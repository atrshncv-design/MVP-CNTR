## 1. Что решает платформа и для кого (факт из кода)

**Проблема из кода/PRD §4-5:** длительный цикл НИОКР по ГОСТ Р 58048-2017 (УГТ 1-9), разрозненные реестры участников, отсутствие единого окна для КЗ/ИП и верификации зрелости. Платформа — B2B/B2G-инфраструктура ЦНТР: собирает проекты, верифицирует УГТ, связывает заказчика-исполнителя-производителя через matching, формирует документы и аналитику.

**Роли в коде (8 активных + 1 архивная):**
- `gk_customer` — ГК-заказчик (User.role.primary), `rd_executor`, `scientific_org` (единый shell с rd_executor), `serial_manufacturer`, `regulating_organization`, `auditor`, `investor`, `cntr_admin`, `cntr_manager`. Эксперт УГТ удалён в P1 (стало 8). Матрица — `technozrelost-frontend/src/lib/roles.ts:46` (`ROUTE_ALLOWED_ROLES`), fail-closed. Backend RBAC — `app/api/v1/auth.py` + `membership.py`/`manager.py` + `users.py`. 9-я роль «эксперт» — legacy в PRD §3, в коде изъята.

**Новые роли кроме 9 из ТЗ:** `UserProfile` (профессиональный профиль, независим от проектной роли) и `UserOrganization` (пользовательская орг, отделена от справочника `organizations`). Обе — тикет 03 Friday RC (`app/db/models.py:653`, `683`).

## 2. Архитектура (факт)

**Запрос:** browser → `nginx:443` (TLS `nginx/certs/`) → `frontend:3000` (SSR) / `backend:8000` ×2 реплики (round-robin). Браузер — относительный `/api/v1/*` (rewrites `next.config.ts`), SSR — `API_URL_INTERNAL` (`src/lib/public-api.ts:30`).
**БД:** PostgreSQL 16 pgvector, Primary `:5432` (запись), Replica `:5433` (чтение `get_read_db()` — реестры/каталоги). Пул `10+20` ×2 реплики = 40, `max_connections=100` резерв 10 (guard-тест `tests/test_db_pool.py`).
**Файлы:** MinIO + ClamAV fail-closed (`app/services/file_storage.py`), лимит 25 МБ файл / 32 МБ body, pending→409.
**Аутентификация:** JWT HS256 access 60м / refresh 14д, NextAuth Credentials (`src/auth.config.ts:22`) авто-рефреш за 5 мин, throttle `app/services/auth_throttle.py`.
**Инфраструктура:** `technozrelost-backend/infra/docker-compose.prod.yml` (prod: db/db-replica/redis/backend×2/frontend/nginx/prometheus/grafana/backup-timer/wal-offsite/alerter), dev — `infra/docker-compose.yml` (pg-primary/pg-replica/minio/clamav).

## 4. Сущности и путь проекта

**Сущности (факт моделей):** User, Role, Permission, Project, ProjectMember, ProjectInvite, QuestionnaireResult, AssessmentTemplate/Checkpoint/Answer, ProjectAssessment, ControlPoint, PromotionRequest, ProjectDocument, VerificationDocument, AuditTrailEntry, RagDocument (tuno/kaba), Organization (справочник), Technology (проекция Project где УГТ≥7), UserProfile, UserOrganization, OrganizationMember, NioktrCard, NewsCategory/Tag/Post/Media, Achievement/UserAchievement/ProjectAchievement, Notification/Outbox, StageRequirement.

**Путь проекта (код):** `draft → auto_confirmed → published → active → completed` + ответвления `→ rejected` / `→ archived`. Hard-gate: `rejected`+rejection_reason → бейдж «Возврат на УГТ N». Создание (`POST /projects`) → анкета (`POST /{id}/questionnaire`) → документы (`POST /{id}/verification-doc`) → заявка повышения (`PromotionRequest`) → КТ (`PATCH /control-points/{id}` Go/No-Go) → публикация (`PUT /{id}/publish`) → архив.

## 5. AI-роль (факт)

- **Сейчас:** внешний OpenAI-совместимый LLM (`LLM_API_BASE/KEY/MODEL`), по умолчанию `llm_gateway_enabled=false` (N-05, ПДн не покидает контур). Без ключа — no-op. Эмбеддинги — CPU-hashing (1536 dim), не модель. RAG — tuno (реестры) / kaba (ГОСТ) два ivfflat-индекса.
- **GPU:** не требуется (docs/СЕРВЕР-ТРЕБОВАНИЯ-2026.md:31).
- **Matching:** скриптовый fallback детерминирован; LLM-rerank код готов (`matching.py:152`), но выключен флагом.
