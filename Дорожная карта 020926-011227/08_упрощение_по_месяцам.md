## Укрупнение в 5 сезонных вех (как просил)

### 1) до 12.2026 — Прод-стенд + пилот
- **09.26** подготовка к выгрузке + бюджет
- **10.26** деплой + нагрузка + кибербез + реестр компетенций ручной
- **11.26** AI-агенты УГТ/реестры + админ-панель + подготовка демо Главе
- **12.26** пилот 5–10 орг + экспорт CSV + RAG tuno — **веха 1**
- Критерий: прод жив, 5 открытых реестров, RAG tuno отвечает, пилот сквозной, демо Главе

### 2) до 03.2027 — Юр-база + облако смыслов + matching
- **01.27** договоры/РИД (S-A5/B5/D5)
- **02.27** облако смыслов S-A4
- **03.27** госпрограммы S-B4 + matching LLM S-D6 — **веха 2**
- Критерий: проект↔нацпроект, РИД поле, облако виджет, matching топ-5

### 3) до 06.2027 — Меры + генерация + внешние данные
- **04.27** меры поддержки S-E2 + связь проект↔мера
- **05.27** генерация 5 шаблонов F08
- **06.27** реестры внешних данных (ФИПС+другие) S-D1 — **веха 3**
- Критерий: справочник мер, 5 шаблонов не мок, внешние реестры live

### 4) до 09.2027 — Локальный LLM + прогноз + пром-proof
- **07.27** локальный LLM контур kaba S-C6
- **08.27** прогноз S-C7
- **09.27** нагрузка + граф цепочек S-A3 — **веха 4**
- Критерий: kaba локально, прогноз ретро-тест, 500 RPS + 3 цепочки

### 5) до 12.2027 — Региональная LLM как НИОКР + финал
- **10.27** старт НИОКР региональная LLM (S-C6)
- **11.27** продолжение НИОКР LLM
- **12.27** всё вместе + пилот НИОКР LLM — **веха 5**
- Критерий: все 31 смысл live, 1000 проектов/2000 орг/10k польз, НИОКР LLM пилот, KPI Г

> Масштаб Q07 В (2000/10k/1000) распределён по вехам 1→5; локальный контур Q06 — 07.27, собственная LLM — 10–12.27 как НИОКР.
