## Наблюдения

1. **Перекрытия:** S-A1 ≈ реестр-движок для S-B3/S-E2; S-B6 ≈ S-D6 + S-A2; S-C6 ≈ ядро для S-A4/S-C7; S-D3/D4 ≈ две стороны одного UX.
2. **Вопросы vs фичи:** 7 из 31 сформулированы как «Определить…» (S-C1,C3,C4,C8,D2,D3,D5) — это задачи на исследование/решение, без них нельзя оценить трудоёмкость зависимых фич.
3. **Пустых «прочерков» нет:** один смысл нельзя потерять — каждый получает строку в `07_смыслы_→_функции_→_этапы.md` с критерием готовности; широкие смыслы (S-B2, S-C6) делятся на подфункции.
4. **Внешнее пересечение:** S-D1/D2/D7 — международный контур; решение по нему влияет на S-C3 (доступы) и S-C6 (какие данные можно в LLM).
