# Свой домен вместо sslip.io (R08, таск 07)

## Почему с телефонов только VPN

Прод живёт на техническом имени `<ipv4>.sslip.io`. Это wildcard-DNS:
имя резолвится без покупки домена, но репутационные фильтры мобильных
операторов режут такие зоны — с телефона сайт открывается только через VPN.
Лечится только собственным именем. Покупка имени — за владельцем
(деньги и выбор имени), код уже готовит переключение.

## Что уже готово в коде

- Переключение адресов — значением `PUBLIC_HOST` в `infra/.env.production`,
  без правок кода (та же переменная тянет сертификат, гейт и редирект).
- Сертификат на новое имя выпускается/продлевается тем же ACME-процессом
  (`infra/tls_issue.sh` / `infra/tls_renew.sh`, Let's Encrypt).
- Старое имя редиректит на новое кодом 301 (HTTP и HTTPS).
- Гейт `infra/tls_deploy_gate.py` принимает оба формата имён и проверяет,
  что сертификат покрывает оба имени переходного периода.

`vash-domen.ru` ниже — плейсхолдер. Гейт и скрипты его отклоняют:
впишите купленное имя.

## Инструкция для владельца (без терминала)

1. **Купить имя** у любого регистратора (например, `cntr-prod.ru` —
   имя выбираете вы). Оплата и выбор — ваши.
2. **DNS**: A-запись имени → IP сервера (адрес подскажет оркестратор).
   Подождать распространения (обычно минуты, иногда часы).
3. **Вписать** через файловый менеджер в `technozrelost-backend/infra/.env.production`
   одним именем ВЕЗДЕ в трёх строках + старое имя в четвёртой:
   ```ini
   PUBLIC_HOST=cntr-prod.ru
   NEXTAUTH_URL=https://cntr-prod.ru
   CORS_ORIGINS=https://cntr-prod.ru
   LEGACY_PUBLIC_HOST=1-2-3-4.sslip.io
   ```
   `LEGACY_PUBLIC_HOST` — текущее техническое имя (взять из старой строки
   `PUBLIC_HOST` до правки). Остальные строки файла не трогать.
4. **Сообщить** оркестратору «готово» — дальше операторская часть:
   `./infra/tls_issue.sh` (сертификат тем же процессом, сразу на оба имени),
   затем `./infra/deploy.sh` (гейт + 301-редирект + проверка).
5. **Проверить с телефона без VPN**: новое имя открывается (200),
   старое имя перебрасывает на новое (301).

## После переходного периода

Когда старое имя больше не нужно: убрать строку `LEGACY_PUBLIC_HOST`
(или оставить пустой) и сообщить оркестратору для перезапуска —
редирект выключится, сертификат останется на новом имени.
Продление сертификата идёт как раньше (`infra/tls_renew.sh` по cron),
ничего нового делать не нужно.

## Оператору (кратко, полный процесс — README-DEPLOY.md)

```bash
# DNS нового имени уже на IP сервера, .env.production заполнен владельцем
./infra/tls_issue.sh   # standalone :80, сразу -d новое -d старое
./infra/deploy.sh      # гейт SAN обоих имён → рендер 301 → health-гейт
curl -I https://<старое>  # 301 Location: https://<новое>/...
```
