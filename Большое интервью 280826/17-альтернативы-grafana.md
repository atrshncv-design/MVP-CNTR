# 17 — Альтернативы Grafana — чем закрыть наблюдаемость

Источник Q20

**Задача:** показать главе стабильность (99.9%, RPO/RTO) и тебе видеть тренды, не только аварии Telegram.

| Инструмент | Плюсы для solo B2G | Минусы | Для тебя |
|---|---|---|---|
| **Grafana внутрь** `compose:339` | Готовые графики, `prometheus.yml` скрейпит `metrics.py`, `expose` не наружу `INF-07` | 300МБ, ещё один пароль `GRAFANA_ADMIN_PASSWORD` | 1 день фронт-отчётности, как решил |
| **Только Prometheus + Alerter** `alerter.py:32` | 0 доп RAM, Telegram за 2м уже закрывает 99.9%, проще | Нет графиков 7 дней, главе не показать | Достаточно для `solo` до 01.11, но не для демо |
| **LLM-отчёты** `15-отчетность` | Красивые PDF с прогнозами, берёт `admin/stats` агрегаты | Нет realtime, галлюцинации | Идеален для главы `01.12`, дополняет Grafana |
| **Datadog/NewRelic** | SaaS, 0 хостов | Деньги, данные наружу (152-ФЗ нельзя) | Не подходит B2G |
| **Custom Next.js дашборд** |reuse `frontend` `dashboard/profile` | Писать код 3 дня | Избыточно |

**Лучшее для тебя:** `Prometheus+alerter` (ядро 99.9%) + `LLM-отчёты` (красиво главе) — Grafana опциональна. Если хочешь графики — оставь Grafana внутрь как 1д фронт, иначе выключи `grafana` в `compose.prod.yml` и оставь только `prometheus`+`alerter`.
