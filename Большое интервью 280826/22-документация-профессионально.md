# 22 — Документация профессионально (мгновенные обновления)

Источник Q24

Не отрывочные md, а техдока крупной платформы:
- `docs/architecture/` (C4: context/container/component, карта 02)
- `docs/api/` (OpenAPI `app/main.py` 25 роутеров)
- `docs/db/` (модели `models.py`, миграции 0028, индексы Hash/B-Tree)
- `docs/infra/` (compose.prod.yml, deploy.sh, RPO/RTO, runbook 20)
- `docs/adr/` `0001-...md` 5 строк (решение/почему/риск)
- `docs/runbooks/` (деплой, PITR, инцидент)

Процесс: feature → spec.md → tickets → code + test → сразу docs/<раздел> + `git commit` (DoD Plan.md:214). CI проверяет `docs` не устарели (линк на код). Свежая всегда.
