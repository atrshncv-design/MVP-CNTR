# 02 — Публичный read-only AI-консультант

**What to build:** Доступный без входа консультант по Центру, ролям, правилам и использованию платформы с источниками и честным отказом.

**Blocked by:** 01 — Редакционный workflow базы знаний.

**Status:** ready-for-agent

- [ ] Ответ использует только published RAG и показывает источник.
- [ ] Консультант не получает проекты, пользовательские файлы, секреты или tools.
- [ ] Вопрос вне базы получает честный ограниченный ответ без выдумывания.
- [ ] Генерация документов и изменение данных недоступны.
