# 03 — Личные профили и организации

**What to build:** Дать человеку личный профиль, возможность создавать организации и вступать в несколько организаций, а менеджеру — проверять профиль перед публикацией.

**Blocked by:** 02 — Безопасная очистка репозитория

**Status:** ready-for-agent

- [ ] Основная роль определяет профильный реестр, но не проектные права
- [ ] Пользователь может состоять в нескольких организациях
- [ ] Профиль имеет состояния draft/pending/verified/rejected
- [ ] Непроверенные профили отсутствуют в публичных реестрах
- [ ] RBAC и API/UI покрыты тестами
