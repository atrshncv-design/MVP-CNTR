# 07 — Универсальные комплекты и автозаявка

**What to build:** Дать каждому переходу УГТ фиксированный универсальный комплект и автоматически создать заявку после появления последнего чистого обязательного документа.

**Blocked by:** 05, 06 — оценка и безопасные документы

**Status:** ready-for-agent

- [ ] Справочник версионирован и не генерируется AI в runtime
- [ ] UI показывает обязательные, загруженные и отсутствующие документы
- [ ] Триггер не зависит от автора последнего файла
- [ ] Одинаковый неизменённый комплект не создаёт дубликат
- [ ] Заявка хранит снимок версий документов
