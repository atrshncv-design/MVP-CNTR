# 07 — Универсальные комплекты и автозаявка

**What to build:** Дать каждому переходу УГТ фиксированный универсальный комплект и автоматически создать заявку после появления последнего чистого обязательного документа.

**Blocked by:** 05, 06 — оценка и безопасные документы

**Status:** done

- [x] Справочник версионирован и не генерируется AI в runtime
- [x] UI показывает обязательные, загруженные и отсутствующие документы
- [x] Триггер не зависит от автора последнего файла
- [x] Одинаковый неизменённый комплект не создаёт дубликат
- [x] Заявка хранит снимок версий документов

Реализовано: миграция 0019 — `promotion_request_documents` (неизменяемый снимок версий заявки, UNIQUE на (request, document)) и `stage_requirements.template_version=v1`; `stages.py` — единый хелпер `_trigger_application` (автотриггер полного комплекта), файловый роут `POST /projects/{id}/stage-document-file` (multipart, MinIO+ClamAV, **только clean засчитывается и инициирует заявку**), guard US 56 (неизменённый отклонённый комплект → 409, сравнение по sha256 на требование), `uploaded` только для clean-файлов/legacy-текста; `template_version` в API. Backend `bb1e0f2` (**135/135 pytest**, ruff чист; 6 новых тестов `test_requirement_sets.py`). Frontend `202e55b`: stage-progress-panel — файловый upload (25 МБ, статус антивируса), версия справочника в UI, обязательные/загруженные/отсутствующие.
