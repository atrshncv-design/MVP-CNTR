# Выбор направления удмуртской темы (тикет 15)

**Дата:** 05.08.2026
**Статус:** выбран дефолт для продолжения конвейера (по указанию Functional
Validator закрыть все тикеты без остановки на ожидании).

## Концепции (реальные HTML, чёрно-красно-белая технологическая стилистика)

| # | Файл | Идея |
|---|------|------|
| А | `themes/concept-a-geometry.html` | «Техно-геометрия»: восьмилучевая звезда как маркер восьми уровней УГТ, строгая геометрия, карточки с красной гранью |
| Б | `themes/concept-b-red-contour.html` | «Красный контур»: контурная звезда, красная линия-активность в навигации, чипы-фильтры, таблица проектов с прогресс-барами |
| В | `themes/concept-c-udmurtia.html` | «Удмуртия индустриальная»: региональный подзаголовок, пунктирная красная линия, круглая эмблема со звездой, статистика реестра |

Все концепции: восьмиконечный мотив функционален (SVG), герб не используется,
используют общие дизайн-принципы текущего дизайн-кода (Manrope, светлый фон).

## Решение

**Выбрана концепция А «Техно-геометрия»** как дефолтная для тикета 16
(переключатель темы + семантические токены). Functional Validator может
перевыбрать концепцию в любой момент; тема реализуется как `data-theme="udmurt"`,
поэтому смена решения не потребует переписывания кода — только правки токенов.
