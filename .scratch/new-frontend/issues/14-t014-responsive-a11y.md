# T-014 — Responsive and accessibility pass

Status: done
Blocked by: все P0-тикеты (финальный проход)

## Цель
Финальный сквозной проход: клавиатура и фокус, семантика для скринридеров, сводки графиков/карт, мобильные флоу, reduced motion, контраст и переносы длинного русского текста.

## Зависимости
T-001…T-013.

## Изменяемые файлы / области
Аудит и точечные правки по всему `platform/src/`:
- Клавиатура: все действия доступны с клавиатуры, видимый фокус во всех темах.
- Семантика: заголовки по иерархии, landmarks, label'ы форм, aria для меню/диалогов/bottom-sheet.
- Графики/карты: текстовые сводки (альтернатива не только цвет/фигура).
- Статусы: не только цвет (число+подпись+форма) — проверка всех status-badge/ugt-badge.
- Мобильные флоу: customer/partner/employee критические сценарии (Design.md §8.3: открыть dossier, статус и следующее действие, уведомления, одобрение/уточнение, поиск, короткая заявка).
- Нет критического действия на hover; нет горизонтального overflow.
- reduced motion; контраст AA в 3 темах; переносы длинных русских названий (НИОКТР!) в карточках/таблицах.

## Сценарий пользователя
Пользователь с клавиатуры и скринридером проходит: поиск НИОКТР → открытие карточки; исполнитель — подача технологии с доказательствами; сотрудник — решение по задаче. На мобильном те же сценарии без потери функциональности.

## Acceptance criteria
- [ ] Критические флоу трёх ролей работают на мобильном.
- [ ] Ни одно критическое действие не зависит от hover.
- [ ] Все состояния читаемы во всех темах.
- [ ] Нет горизонтального overflow в обязательных маршрутах (проверка скриптом на 390px и 1440px).
- [ ] Контраст текста AA (автоматизированная проверка ключевых пар).
- [ ] Тач-цели ≥44px на управляющих элементах.

## Состояния
Все состояния из T-005 перепроверяются на a11y.

## Desktop / mobile
Этот тикет и есть mobile/a11y-проход: 1440px и 390px (CDP-эмуляция), клавиатура, скринридер-семантика (основные landmarks/labels).

## Данные и adapter requirements
Нет новых данных; проверка на реальных данных (НИОКТР) и фикстурах.

## Критерии визуальной проверки
Скрипт-чеки (overflow, тач-цели, контраст) + ручной браузерный проход сценариев 3 ролей в 3 темах на 2 viewport'ах; скриншоты; lint/tsc/build зелёные.
