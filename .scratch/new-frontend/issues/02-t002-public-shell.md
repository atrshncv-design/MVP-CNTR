# T-002 — Public shell and task-based navigation

Status: ready-for-agent
Blocked by: T-001

## Цель
Публичный каркас: identity Центра, задача-first навигация, два равных действия («Найти решение» / «Представить технологию»), глобальный поиск (entry), переключатель тем, адаптивная мобильная навигация, футер.

## Зависимости
T-001 (токены/темы). Даёт каркас для T-006 (discovery) и T-013 (регистрация).

## Изменяемые файлы / области
- `platform/src/app/(public)/layout.tsx` — публичный shell: header + footer.
- `platform/src/components/public-header.tsx`, `public-footer.tsx`, `nav-task-list.ts` (данные навигации), `global-search.tsx` (entry, реальный поиск — T-006).
- `platform/src/app/(public)/page.tsx` — главная: hero с обещанием экосистемы, два равных действия, путь технологии, вход в карту/реестры, «о Центре» (композиция Design.md §12.1; БЕЗ герой→3 карточки→CTA по умолчанию).
- Временные заглушки `not-found`, `loading` для публичной группы.

## Сценарий пользователя
Посетитель без знания внутренней структуры: (1) находит технологию через «Найти решение»; (2) подаёт технологию через «Представить технологию»; (3) находит партнёра и меру поддержки; (4) переключает тему; (5) на мобильном открывает бургер-меню — те же задачи доступны.

## Acceptance criteria
- [ ] Header: identity, задача-first навигация (Find a solution / Present a technology / Find a partner / Find support / Research and NIOKTR / About), глобальный поиск, тема, вход, primary-действие.
- [ ] Два главных действия равнозначны визуально (не «герой + мелкая кнопка»).
- [ ] Публичные страницы не требуют знания внутренних названий разделов.
- [ ] Мобильное меню: drawer или аккордеон, текущий раздел виден, primary-действие не перекрывает контент.
- [ ] Футер: служебные ссылки, контакты, методология/УГТ, реестры.
- [ ] Все три темы + mobile.

## Состояния
Header/футер стабильны при loading/error публичных страниц (скелеты в `loading.tsx`, ошибка с retry в `error.tsx`).

## Desktop / mobile
Desktop: max-width 1200–1280px, padding 32px. Mobile: padding 20px, бургер, тач-цели ≥44px, без hover-зависимых меню.

## Данные и adapter requirements
Только статический контент + `getHomeSummary()` (T-004) для real-data-превью на главной. Пока адаптера нет — секции «последние записи» показывают честное пустое состояние «Раздел готов к наполнению».

## Критерии визуальной проверки
Браузер: главная в 3 темах, desktop 1440px и mobile 390px (CDP `Emulation.setDeviceMetricsOverride`), скриншоты; меню навигации кликабельно; консоль без ошибок; `npm run lint && npx tsc --noEmit && npm run build` зелёные.
