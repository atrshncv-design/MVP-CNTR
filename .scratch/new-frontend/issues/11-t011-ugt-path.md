# T-011 — UGT path, checkpoints and evidence

Status: ready-for-agent
Blocked by: T-005 (УГТ-модель), T-009 (путь в кабинете), T-010 (проверка)

## Цель
Полный путь УГТ 1–9: справочник уровней (`/levels`, `/methodology`), 4 измерения готовности, checkpoint-путь, текущий и целевой уровень, чек-лист доказательств, переход N→N+1, трёхлетний отчётный путь (entry).

## Зависимости
T-005 (ugt.ts), T-009 (path в кабинете партнёра), T-010 (решение о переходе).

## Изменяемые файлы / области
- `platform/src/app/(public)/levels/page.tsx`, `levels/[id]/page.tsx`, `methodology/page.tsx` — справочник: простой язык ДО деталей; 9 уровней, 4 измерения, требования к доказательствам, правила переходов; примеры — только реальные/разрешённые.
- `platform/src/components/ugt/` — `ugt-path.tsx` (горизонтальный путь desktop, вертикальный mobile; каждый checkpoint: номер УГТ, название, состояние доказательств, ответственный, следующее действие, дата/срок), `ugt-dimensions.tsx` (4 оси, текстовые пояснения), `ugt-radar.tsx` (дополнительный, не единственное объяснение), `checkpoint-card.tsx` (критерии + недостающие доказательства), `transition-n-to-n1.tsx` (подготовка/проверка/одобрение — НЕ «текущий уровень»).

- `platform/src/app/(app)/partner/technologies/[id]/path/page.tsx` — путь внутри кабинета (связка с T-009).

## Сценарий пользователя
Посетитель: «Что такое УГТ?» → методология простым языком → 9 уровней → примеры только реальные. Исполнитель: видит текущий уровень (проверенный), что нужно для следующего checkpoint, загружает недостающие доказательства, подаёт N→N+1. Сотрудник: проверяет доказательства и принимает решение о переходе.

## Acceptance criteria
- [ ] Проверенный уровень визуально отличим от чернового прогресса.
- [ ] Каждый checkpoint: критерии + недостающие доказательства + ответственный + следующее действие.
- [ ] Desktop-путь становится читаемой мобильной последовательностью.
- [ ] Радар — дополнительный, не единственное объяснение готовности.
- [ ] УГТ не подаётся как «общая оценка качества» (CONTEXT.md).
- [ ] Методология: 9 уровней, 4 измерения, требования, переходы, трёхлетний путь — с честными пустыми местами там, где нет реальных примеров.

## Состояния
УГТ: текущий уровень (verified), переход (preparing/under_review/approved), недостающие доказательства, blocked; справочник — content.
