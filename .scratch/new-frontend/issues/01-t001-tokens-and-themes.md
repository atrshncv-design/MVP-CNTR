# T-001 — Semantic design system and three themes

Status: done
Blocked by: —

## Цель
Фундамент всего контура: семантическая токен-система, типографика, геометрия, состояния фокуса, три темы (светлая/тёмная/удмуртская) на одной UX-структуре. Никакой компонент не должен хардкодить цвета тем.

## Зависимости
Нет (первый тикет). После него: T-002, T-003, T-004, T-005.

## Изменяемые файлы / области
- `platform/src/app/globals.css` — ЕДИНЫЙ файл токенов: `:root` (светлая), `[data-theme="dark"]`, `[data-theme="udmurt"]`; Tailwind v4 `@theme inline` маппинг → утилиты `bg-canvas`, `text-primary`, `border-subtle`, `bg-accent` и т.д.
- `platform/src/lib/theme.ts` — логика: чтение сохранённого выбора (`localStorage` ключ `nfr-theme`: `light|dark|udmurt`), `prefers-color-scheme` по умолчанию, применение `data-theme` на `<html>`.
- `platform/src/components/theme-toggle.tsx` — переключатель (сегмент-контрол из 3, без пилюль-кнопок).
- `platform/src/app/layout.tsx` — стартовый inline-скрипт БЕЗ FOUC (ставит `data-theme` до рендера), подключение шрифтов.
- `platform/package.json` — шрифты: `@fontsource-variable/golos-text` + `@fontsource/ibm-plex-mono` (если пакетов нет — fallback: next/font/google Golos_Text/IBM_Plex_Mono; если и он недоступен — системный стек, зафиксировать в комментарии).

## Сценарий пользователя
Посетитель заходит на любую страницу в светлой теме (или по системной настройке), переключает тему на тёмную и удмуртскую — структура, статусы и контраст не ломаются, выбор запоминается при перезагрузке.

## Acceptance criteria
- [ ] Один и тот же тестовый компонент (карточка, кнопка, бейдж статуса, таблица) корректен во всех трёх темах.
- [ ] Удмуртская тема — не замена цветов: чёрно-красно-белая база, красный только как акцент/текущий путь, восьмиконечная звезда и модульная геометрия в разделителях/маркерах/прогрессе (SVG-паттерны), флаг НЕ на каждом экране.
- [ ] Семантика статусов и УГТ одинакова: низкий 1–3, средний 4–6, высокий 7–9; не только цвет — число + подпись + иконка/форма.
- [ ] Нет хардкода цветов тем в компонентах (grep по `#hex` в компонентах = пусто, кроме токенов и тестовых данных).
- [ ] Контраст WCAG AA в трёх темах: text-primary/secondary/muted на canvas ≥4.5:1, белый на accent-strong ≥4.5:1 (светлая `#1D4ED8`, тёмная `#2563EB`, удмуртская `#B91C1C`), статусные тексты на своих soft-тинтах ≥4.5:1.
- [ ] Фокус: видимое кольцо 2px с отступом во всех темах; disabled-состояния различимы.
- [ ] reduced-motion: `@media (prefers-reduced-motion: reduce)` отключает декоративные переходы.
- [ ] Переключение тем без FOUC; выбор персистится.

## Состояния
Тема переключается в любой момент; выбранная тема применяется ко всем состояниям (loading/empty/error/success) — проверка на этапе T-005, но токены закладываются сейчас.

## Desktop / mobile
Токены те же; на мобильном проверяется контраст поверхностей и тач-цели (минимум 44px для управляющих элементов).

## Данные и adapter requirements
Не требуются. Шрифты — npm-зависимости (не данные).

## Критерии визуальной проверки
Браузер: `http://localhost:3000` (НЕ 127.0.0.1 — Next 16 CORS). Проверка темы: `getComputedStyle(document.body).backgroundColor` — светлая `#F6F5F1`, тёмная `#0B0E13`, удмуртская `#F4F2EE`. Прогнать: карточку, кнопки (primary/secondary/quiet/destructive), бейджи статусов, таблицу, форму с фокусом — в трёх темах. Скриншоты каждой темы.
