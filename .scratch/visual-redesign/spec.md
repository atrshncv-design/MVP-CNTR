# Visual Redesign — spec (дизайн-раунд 2)

Статус: черновик. Основание: вердикт Functional Validator «2/5 против 4/5 старого» + грилл (2 вопроса).

## Контекст и вердикт

Новый фронтенд функционально богаче старого, но визуально проигрывает. Зафиксированные претензии (дословно по гриллу):

1. «Графиков нет, радара нет» — старая главная имела радар 4 измерений; в новой визуализации данных отсутствуют.
2. «Вёрстка кривая и страница не влазит целиком в экран» — **подтверждённый баг**: на 1280px `scrollWidth=1444` (>viewport на 164px), из хедера выпирают «Войти»/«Подать технологию».
3. «Цвета остались те же нейросетевые» — палитра воспринимается как типовой AI-слоп (синий акцент, тёмно-серые поверхности), несмотря на токены.
4. «Новые орнаменты и элементы дизайна не появились» — удмуртская геометрия/звезда существует в коде, но визуально не считывается.
5. «Шрифты тоже старые и нейросетевые» — типографика без характера.
6. «Сломал старый дизайн» — старый был 4/5 (плотность, шкала УГТ «тёплые→холодные», нумерованные шаги, карточки ролей, 9 уровней).

## Методология

Скилл **impeccable.style** (по указанию валидатора): анти-slop-словарь + «вырваться из распределения» (амбициозные визуальные миры). Ключевые анти-паттерны из impeccable, которые надо убить:

- **AI beige** — нейтральная бежево-серая база без характера.
- **Status-chip soup** — десятки одинаковых бейджей без иерархии.
- **Everything equal** — всё одной важности: нет визуальной иерархии.
- **Cards in cards** — карточки внутри карточек без смысла.
- **Vague headline / Generic CTA** — «Улучшите свой потенциал» вместо конкретики.
- **Italic serif accents** — фирменный AI-приём «италик-сериф-цитата», которого нет в бренде.
- **Neural blue** — дефолтный акцент `#2563EB`/`#1D4ED8`, который читается как «сделано нейросетью».

Вместо этого: **одна сильная идея на экран**, выраженная через цвет/типографику/геометрию; **иерархия через контраст размера и плотности**, а не через бейджи; **фирменные визуальные артефакты** (радар, шкала УГТ, звезда), которые невозможно перепутать с шаблоном.

## Решения грилла (обязательные)

- **Три равноправные темы с полноценной идентичностью** — без дефолта-перекоса. Каждая тема — свой визуальный мир (решено: Q2).
- **Цвета НЕ пересобираем** (решено: Q3 «оставь текущие цвета»): значения токенов остаются как есть; визуальный характер поднимаем типографикой, геометрией, графиками, плотностью и вёрсткой. Единственная уступка: если субагент D-01 уже поменял значения — ОТКАТИТЬ к текущим.
- **Hero главной = КОМБО** (решено: Q4): радар 4 измерений + мини-трек пути УГТ + счётчики живых данных.
- **Кабинеты получают ПОЛНЫЙ визуальный пасс** (решено: Q5): типографика, плотность, геометрия — и кабинет участника, и операционный центр (новый тикет D-09).
- **Акцидентная типографика — подбором** (решено: Q6): субагент-дизайнер выбирает пару с проверкой кириллицы, варианты показываются валидатору до фиксации.

## Допущения (приняты за пользователя, можно вето)

- **A1. Радар 4 измерений** — возвращается как компонент-визуализация: SVG, данные из `readiness` досье/фикстур; в hero главной — на реальных данных НИОКТР-карточек или честное состояние «нет данных для радара».
- **A2. Шкала УГТ** — семантический градиент «низкие → тёплые, высокие → холодные» (как в старом), сквозной для всех трёх тем; цвет никогда не единственный канал (число + название + band).
- **A3. Графики** — SVG без библиотек (recharts не добавляем без нужды): радар, бар-чарт распределения УГТ (аналитика Центра), мини-спарки на дашбордах. Только реальные/фикстурные данные, источник подписан.
- **A4. Типографика** — акцидентная пара подбирается субагентом-дизайнером (Unbounded как стартовый кандидат, проверка кириллицы, 2–3 варианта → на показ валидатору); `--font-sans` остаётся Golos Text; моноже для ID/кодов — только метаданные. Без италик-сериф-акцентов.
- **A5. Плотность главной** — возвращаются проверенные секции старого в новой редакционной сетке: нумерованные шаги 01/02/03 («Как это работает»), карточки ролей, блок «Что означает уровень».
- **A6. Живость первого экрана** — «готов к наполнению» уходит с первого экрана: вместо пустых блоков — реальные записи НИОКТР (400 карточек), ссылки на реестры, честные счётчики «0 технологий · 400 исследований · 9 ролей».
- **A7. Палитры тем** — НЕ пересобираем (Q3): текущие значения токенов остаются, контраст уже проверен (T-001). Отменено прежнее A7 о пересборке.
- **A8. Баг вёрстки** — хедер на 1280px: переполнение 164px. Фикс breakpoint-логики навигации и CTA-группы.
- **A9. Кабинеты** — полный визуальный пасс обоих контуров (Q5): шапки/сайдбар/дашборды получают фирменную типографику, маркеры-звёзды (только udmurt), шкалу УГТ, спарки; инструментальность и плотность сохраняются.

## Область изменений

Файлы: `src/app/globals.css` (токены v2), `src/components/public-header.tsx`, `src/app/(public)/page.tsx` (главная), `src/components/home/*` (новые секции), `src/components/radar.tsx` + `src/components/charts/*` (новые), `src/components/ugt/*` (шкала), `src/lib/ugt.ts` (палитра уровней), `src/lib/theme.ts`, кабинетные шапки (`top-bar`, `sidebar` — акцентные правки), `operations/analytics` (графики).

НЕ меняем: data layer, маршруты, логику состояний, типы, адаптер.

## Порядок

1. Токены v2 + типографика (база для всего).
2. Фикс вёрстки хедера.
3. Радар + графики.
4. Главная: hero, шаги, роли, уровни.
5. Удмуртская идентичность (звезда/орнамент — видимая).
6. Шкала УГТ + мини-спарки в кабинетах.
7. Финальный визуальный QA: 3 темы × ключевые экраны × desktop/mobile.

## Критерии приёмки

- Нет горизонтального скролла на 1280px и 390px.
- Радар 4 измерений виден на главной (или честное «нет данных»).
- Графики в аналитике Центра на реальных данных.
- Шкала УГТ с цветовой семантикой во всех трёх темах.
- Удмуртская звезда/орнамент считываются визуально (не фон).
- Три темы визуально различны, не «перекраска» одной.
- Нет AI-beige, neural-blue, status-chip soup, cards-in-cards.
- Оценка валидатора ≥ 4/5.

## Риски

- Пересборка токенов затрагивает все экраны → регресс контраста: QA по каждой теме обязателен (AA).
- Удмуртская идентичность может уйти в «фольклорный кич» → держимся современной геометрии (Design.md §8), без флагов на каждом экране.
- Графики SVG без библиотеки — риск переусложнения → минимум: радар + бар-чарт + спарки.
