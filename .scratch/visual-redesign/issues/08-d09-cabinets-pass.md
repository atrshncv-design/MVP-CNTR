# D-09: Кабинеты — полный визуальный пасс (участник + операционный центр)

Blocked by: D-01 (типографика), D-06 (маркеры), D-07 (шкала УГТ), D-05 (спарки)

Status: ready-for-agent

## Цель
Решение грилла (Q5): кабинеты получают ЗАМЕТНЫЙ визуальный пасс — не только акценты. Типографика (display-заголовки), плотность, геометрия, шкала УГТ и спарки — и в кабинете участника, и в операционном центре. Инструментальность сохраняется: кабинеты остаются «инструментальными и ориентированными на действия» (Design.md §3.3).

## Изменяемые файлы
- `platform/src/app/app/layout.tsx` (сайдбар/топбар кабинета) — типографика заголовков, маркеры секций (SectionMark из D-06, только udmurt), плотность.
- `platform/src/app/operations/layout.tsx` (операционный шелл) — то же для Центра.
- `platform/src/components/top-bar.tsx`, `sidebar.tsx`, `mobile-drawer.tsx` — визуальные правки (не логика навигации).
- Дашборды: `src/app/app/customer/page.tsx`, `src/app/app/partner/page.tsx`, `src/app/operations/page.tsx` — заголовки display-шрифтом, KPI-карточки с иерархией (не «everything equal»), спарки (Sparkline из D-05) где есть данные.
- НЕ трогать: логику, маршруты, data layer, формы (их поведение), цвета токенов.

## Требования
1. Заголовки разделов кабинетов — display-шрифт (из D-01); иерархия: заголовок → подзаголовок → метаданные, контраст размеров, а не бейджи.
2. Сайдбар: активный раздел с маркером (SectionMark/звезда — только udmurt-тема; в светлой/тёмной — сдержанный квадрат/полоса), плотность 44px-строк, разделители секций.
3. Топбар: хлебные крошки и заголовок раздела — с display-шрифтом, «хлебные крошки» не кричат (метаданные).
4. KPI-карточки: одно главное число (display), подпись источника, не более 4–6 карточек на экран; без «карточек в карточках».
5. Операционный центр: очередь-таблица сохраняет плотность 56–64px; заголовки страниц — display; маркеры статусов — консистентные.
6. Удмуртская тема в кабинетах: звезда-маркеры и разделители (D-06) — видимы, но не на каждом экране.
7. Анти-slop: никаких status-chip soup (группировать), cards-in-cards, everything-equal.

## Acceptance
- Гейты: lint/tsc/build; браузер :3001: кабинет заказчика и операционный центр в 3 темах, desktop + 390px.
- Заголовки кабинетов — display-шрифт; KPI-карточки имеют иерархию; спарки там, где есть данные, иначе честное «данные появятся».
- Скриншоты: дашборд заказчика + очередь Центра в 3 темах.
