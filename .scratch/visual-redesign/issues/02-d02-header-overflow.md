# D-02: Фикс вёрстки — переполнение хедера на 1280px

Status: ready-for-agent

## Цель
Убить горизонтальный скролл. Подтверждено: на 1280px `scrollWidth=1444` (+164px), выпирают CTA «Войти»/«Подать технологию» (`public-header.tsx`).

## Изменяемые файлы
- `platform/src/components/public-header.tsx` — ТОЛЬКО он (плюс, если нужно, мобильный drawer в нём же).

## Требования
1. На 1280px весь хедер помещается: лого, навигация (задача-first), поиск-entry, тема, «Войти», «Подать технологию» — без переполнения.
2. Проверить текущую breakpoint-логику скрытия подписей навигации (~1300px): она должна срабатывать РАНЬШЕ, чем возникает переполнение. На 1024–1280 — компактный режим (подписи скрыты или навигация в drawer), на <1024 — мобильный drawer.
3. Никаких `min-width`-жёстких значений, ломающих ресайз; все элементы ≥44px тач-цели.
4. Не менять дизайн (цвета/шрифты) — только геометрию/breakpoints.

## Acceptance
- На viewport 1280, 1024, 768, 390: `document.documentElement.scrollWidth <= clientWidth` (проверить в браузере через console).
- Навигация не пропадает бесследно: на планшете либо компакт, либо drawer.
- Гейты: lint/tsc/build зелёные.

## Визуальная проверка
Браузер :3001: ресайз 1440 → 1280 → 1024 → 768 → 390; главная, /research, кабинет (после логина demo).
