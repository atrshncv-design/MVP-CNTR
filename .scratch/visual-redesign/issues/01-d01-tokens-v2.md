Status: ready-for-agent

## Цель
Вердикт: «цвета нейросетевые, шрифты нейросетевые». Решение грилла (Q3): **цвета НЕ пересобираем** — значения токенов остаются как есть. Вся работа D-01 — типографика и подтверждение неизменности палитр.

## Решения грилла (Q3, Q6)
- Цвета: текущие значения остаются (уже проверены на AA в T-001). Если в процессе работы что-то менялось — вернуть.
- Акцидентный шрифт: подобрать 2–3 варианта display-пары с ПРОВЕРКОЙ КИРИЛЛИЦЫ (стартовый кандидат — Unbounded), подключить лучший через next/font; в отчёте показать варианты для валидатора.

## Изменяемые файлы
- `platform/src/app/globals.css` — ТОЛЬКО шрифтовые токены (`--font-display`, заголовочные классы) и, если потребуется, мелочи фактуры (не цвета).
- `platform/src/app/layout.tsx` — подключение display-шрифта через next/font (разрешено).
- `platform/src/lib/theme.ts` — без изменений API.
- НЕ менять: цветовые значения токенов.

## Требования
1. Имена токенов сохранить 1:1 (список в DATA-CONTRACTS §токены). Цветовые значения НЕ трогать.
2. Типографика (Q6): подобрать акцидентный гротеск с поддержкой кириллицы (Unbounded — стартовый кандидат; проверить кириллицу, вес 400–700); `--font-display` для заголовков (h1–h3, hero, секции); `--font-sans` остаётся Golos Text; `--font-mono` IBM Plex Mono (метаданные). Без италик-сериф-акцентов.
3. Заголовочные классы/токены в globals.css переключаются на display-шрифт.
4. В отчёте — 2–3 варианта шрифтов с образцами кириллицы (можно скриншотом /dev/tokens) для выбора валидатором.
5. Демо `/dev/tokens` — обновить, если там захардкожены устаревшие hex (показывать токены, не «нейросетевые» значения из головы).
