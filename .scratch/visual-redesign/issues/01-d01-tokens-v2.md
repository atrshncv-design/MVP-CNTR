# D-01: Дизайн-токены v2 — три идентичности, не «перекраска»

Status: ready-for-agent

## Цель
Пересобрать палитры трёх тем так, чтобы каждая была полноценной идентичностью (вердикт: «цвета нейросетевые», «AI beige»). Убить neural-blue из базовой идентичности светлой/тёмной, дать акцентам характер. Имена токенов НЕ меняются (см. ниже) — меняются только значения.

## Допущения спеки (A1–A8)
A7 (палитры), A4 (типографика). Анти-slop: нет AI-beige, neural-blue, itалик-сериф-акцентов.

## Изменяемые файлы
- `platform/src/app/globals.css` — ТОЛЬКО он. (`:root`, `[data-theme="dark"]`, `[data-theme="udmurt"]`, `@theme inline`, `--font-sans/--font-mono`.)
- `platform/src/lib/theme.ts` — только если нужно добавить метаданные темы (название/дескриптор), API не ломать.

## Требования
1. Имена токенов сохранить 1:1 (список в DATA-CONTRACTS §токены): `--canvas, --surface, --surface-elevated, --border-subtle, --border-strong, --text-primary, --text-secondary, --text-muted, --text-inverse, --accent, --accent-strong, --accent-contrast, --accent-soft, --link, --focus-ring, --status-*, --ugt-low/medium/high, --overlay, --scrim` + soft-тинты. Радиусы и шрифтовые токены — тоже.
2. Светлая: «бумажная редакция». База — тёплая бумага (не серая #F6F5F1-нейтраль, а осознанная тёплая с лёгким кремовым подтоном), текст — графит с тёплым подтоном. Акцент — НЕ синий: глубокий фирменный цвет (рекомендация: тёмно-красный/терракотовый `#A52A2A`-класс с AA-проверкой или графитово-стальной). Один сильный акцент, не два.
3. Тёмная: «инструментальный пульт». База не `#0B0E13`-нейтраль, а с лёгким тёплым/стальным подтоном; акцент приглушённый, без неона (рекомендация: стальной/янтарный, не синий).
4. Удмуртская: чёрный/красный/белый, но не кич: красный `#B91C1C`-класс как акцент, бумага с лёгким подтоном, геометрия — в компонентах (D-06), не в css-паттернах фона.
5. WCAG AA 4.5:1 для текста — проверить каждую пару (текст/фон), отклонения только минимальные с документацией.
6. Типографика (A4): подключить акцидентный гротеск для заголовков (рекомендация: подключить через next/font, например «Unbounded» — НЕ италик-сериф; или другой выраженный гротеск с характером); `--font-sans` остаётся Golos Text для текста; `--font-mono` — IBM Plex Mono, только метаданные. Заголовочные токены (`--text-h1..h3`) — с новым display-шрифтом.
7. Никаких новых цветов вне токенов: все экраны используют токены.

## Acceptance
- `npm run lint` чисто; `npx tsc --noEmit` чисто; `npm run build` зелёный.
- Контраст AA проверен для текстовых пар всех трёх тем (посчитано, не на глаз).
- Три темы визуально РАЗНЫЕ (не перекраска): разная база, разные акценты, разная фактура.
- Демо `/dev/tokens` показывает новые значения; скриншоты трёх тем приложены в отчёте.

## Desktop/mobile
Токены — глобальные; проверить, что breakpoints не сломались (не трогать медиа-логику).

## Визуальная проверка
Браузер :3001: главная + кабинет в трёх темах; подтвердить отсутствие neural-blue и AI-beige.
