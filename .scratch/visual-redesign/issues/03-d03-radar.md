# D-03: Радар четырёх измерений готовности (SVG)

## Цель
Вернуть визуализацию «радар 4 измерений» (старая главная имела её) как переиспользуемый компонент. Данные — `readiness: ReadinessDimensionScore[]` (4 оси: научная, техническая, организационная, производственная).

- НЕ трогать страницы: интеграцию делает D-04.

## Контракт (для D-04)
```tsx
export interface RadarChartProps {
  scores: { dimension: string; score: number }[]; // 0..10
  max?: number; // default 10
  size?: number; // default 260
  labels?: boolean; // подписи осей
  accent?: string; // hex/токен — цвет заливки (по умолчанию var(--accent))
}
export function RadarChart(props: RadarChartProps): JSX.Element;
```
- Честные состояния: `scores.length === 0` → рендерить пустой контур с подписью «Нет данных для радара» (не рисовать ноль).

## Требования
1. Чистый SVG, без библиотек. Полигон данных + контурная сетка (10 уровней или 5), подписи осей.
2. Токены: `var(--text-muted)` для сетки, `var(--accent)`/`var(--accent-soft)` для заливки, `var(--text-primary)` для подписей.
3. `prefers-reduced-motion`: никакой анимации по умолчанию (или только при отсутствии reduced-motion).
4. Доступность: `role="img"` + `aria-label` с перечислением значений («научная 6, техническая 5…»).
5. Масштабируется: `size` меняет ширину, сетка пропорциональна.
