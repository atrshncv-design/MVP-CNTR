# D-06: Удмуртская идентичность — видимая звезда и геометрия

Blocked by: D-01 (токены)

Status: done

## Цель
«Новые орнаменты и элементы дизайна не появились» — удмуртская тема должна СЧИТЫВАТЬСЯ: восьмиконечная звезда, модульная геометрия, чёрно-красно-белое — в ключевых точках, без флагов на каждом экране (Design.md §8, анти-slop).

## Изменяемые файлы
- `platform/src/components/udmurt/*` (новые): `star.tsx` (восьмиконечная звезда SVG, токенизированная), `geometry-divider.tsx` (модульный орнаментальный разделитель), `section-mark.tsx` (маленький маркер-звезда для заголовков разделов).
- Интеграция: `platform/src/components/public-header.tsx` (звезда в логотипе при udmurt-теме), разделители на главной (вызывает D-04 — контракт ниже), `platform/src/components/dossier/dossier-header.tsx` (маркер секции), `platform/src/components/top-bar.tsx` (маркер в кабинетах).
- НЕ трогать: globals.css (токены — D-01), главную целиком (D-04), ugt (D-07).

## Контракт (для D-04 и кабинетов)
```tsx
export function UdmurtStar({ className, size = 24 }: { className?: string; size?: number }): JSX.Element;
// Восьмиконечная звезда (толэзё), цвет — var(--accent), вид — по теме.
export function GeometryDivider({ className, variant = "udmurt" | "light" | "dark" }: ...): JSX.Element;
// Модульный разделитель: удмуртский — ромбы/звёзды; light/dark — сдержанная геометрия.
export function SectionMark({ label, theme }: { label: string; theme: string }): JSX.Element;
// Маркер-звезда перед заголовком раздела (только udmurt; light/dark — точка/квадрат).
```

## Требования
1. Звезда — корректная восьмиконечная геометрия (два квадрата, повёрнутых на 45° — «толэзё»), НЕ иконка из библиотеки.
2. Видимость: в udmurt-теме звезда появляется в логотипе, hero (через D-04), разделителях секций, заголовках кабинетов. В light/dark — сдержанные геометрические маркеры (не звезда).
3. Никаких фоновых css-паттернов на всю страницу; орнамент — это компоненты, а не wallpaper.
4. Токенизация: цвета из токенов, поддержка reduced-motion.
5. SVG: `aria-hidden` для декоративных элементов (кроме SectionMark — он с текстом).

## Acceptance

- Скриншоты всех трёх тем: разделитель секции на главной.
