# D-07: Шкала УГТ — цветовая семантика «тёплые → холодные»

Blocked by: D-01 (токены)

Status: done

## Цель
Вернуть цветовую семантику шкалы УГТ (старая главная: «низкие уровни — тёплые, высокие — холодные»). Цвет — НЕ единственный канал: число + название + band всегда (STATES.md §2).

## Изменяемые файлы
- `platform/src/lib/ugt.ts` — палитра уровней: `UGT_LEVEL_COLORS` (массив из 9 цветов, градиент тёплый→холодный: низкие — тёплые (янтарь/терракота), средние — нейтральные/зелёные, высокие — холодные (сталь/сине-зелёный)); ТОЛЬКО добавлять, не ломать существующие экспорты.
- `platform/src/components/ugt/ugt-track.tsx`, `ugt-level-card.tsx`, `platform/src/components/ugt-badge.tsx` — использовать палитру (цвет уровня, а не band-цвет).
- НЕ трогать: globals.css (D-01), главную (D-04).

## Требования
1. `UGT_LEVEL_COLORS: readonly string[]` длиной 9 (1-индекс), значения — hex с AA-проверкой на фонах тем (тёмные оттенки на светлом фоне, светлые на тёмном — проверять обе).
2. Визуализации: ugt-track заполняется цветом ТЕКУЩЕГО уровня (не band); ugt-badge — тон уровня; в dossiers — маркер уровня с цветом.
3. Все три темы: семантика сохраняется (тёплый→холодный), но тона адаптированы под фон темы.
4. Доступность: цвет дублируется текстом (число+название) — уже есть, сохранить.

## Acceptance
- Гейты: lint/tsc/build; браузер: /methodology/ugt, /dev/tokens, dossier в 3 темах — шкала читается «тёплые→холодные» во всех темах.
- Скриншоты шкалы в 3 темах.
