# 06 — Backup и проверенное восстановление

**What to build:** Зашифрованные отдельные backup БД/файлов с retention, integrity check и восстановлением на чистом окружении.

**Blocked by:** 05 — Воспроизводимый Docker Compose deploy.

**Status:** ready-for-agent

- [ ] Daily 30d и weekly 3m policy реализована конфигурируемо.
- [ ] Backup хранится отдельно от основного stack и не доступен приложению на удаление.
- [ ] Restore test подтверждает целостность БД, файлов и ключевых сценариев.
- [ ] RPO 24h/RTO 4h измерены или честно отмечены как неподтверждённые до сервера.
