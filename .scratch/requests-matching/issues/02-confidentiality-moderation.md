# 02 — Конфиденциальность и модерация запроса

**What to build:** Публичный, платформенный и закрытый режимы запроса с обязательным решением менеджера до публикации.

**Blocked by:** 01 — Черновик технологического запроса.

**Status:** ready-for-agent

- [ ] Видимость каждого поля и вложения соответствует выбранному режиму на backend.
- [ ] Менеджер approve/reject с причиной; решение попадает в audit и уведомления.
- [ ] Закрытый запрос не раскрывается через реестр, поиск, прямой URL или ошибку.
- [ ] Изменение режима повторно проходит модерацию.
