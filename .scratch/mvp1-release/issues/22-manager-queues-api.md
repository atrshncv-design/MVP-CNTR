# 22 — API очередей менеджера ЦНТР (две очереди)

**What to build:** Два набора эндпоинтов для ЛК менеджера. Очередь «Новые проекты»: черновики на апрув (карточка + радар + предварительная оценка) → «Подтвердить и присвоить УГТ N» (проект публикуется, `current_level` = присвоенный) или «Отклонить с причиной» (виден владельцу, исправляет, подаёт снова — история попыток). Очередь «Заявки на повышение УГТ»: заявки со статусом `pending_manager` (документы + заключение системы) → «Подтвердить уровень» (повышение N→N+1) или «Отклонить с причиной». Уведомление менеджеру об автозаявке — in-app в ЛК (не email).

**Blocked by:** 20, 21 — Схема данных, API экспресс-оценки

**Status:** ready-for-agent

- [ ] `GET /api/v1/manager/queue/drafts` — черновики на апрув (только менеджер ЦНТР), карточка + радар + предварительная оценка
- [ ] `POST /api/v1/manager/queue/drafts/{id}/decide` — `approve` (присвоить УГТ N → статус published, попадает в реестры) | `reject` (причина → владельцу)
- [ ] `GET /api/v1/manager/queue/promotions` — заявки на повышение УГТ
- [ ] `POST /api/v1/manager/queue/promotions/{id}/decide` — `approve` (current_level += 1) | `reject` (причина)
- [ ] История попыток по проекту (все решения по апрувам/заявкам) доступна владельцу и менеджеру
- [ ] In-app уведомление менеджеру при появлении автозаявки
- [ ] Тесты: апрув/отклонение черновика, апрув/отклонение повышения, RBAC (только менеджер), причина при отклонении, история попыток
