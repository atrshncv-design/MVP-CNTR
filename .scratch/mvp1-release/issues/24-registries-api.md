# 24 — API реестров: общий реестр проектов + реестр технологий УГТ 7+

**What to build:** Общий реестр проектов для всех ролей (после апрува менеджера): карточки с УГТ-уровнем и радаром, фильтры (УГТ, область технологии, бюджет). Реестр технологий = тот же реестр с фильтром «УГТ 7+» (автоматическое попадание, одна карточка, без новой сущности). Черновики и отклонённые в реестрах не показываются.

**Blocked by:** 20, 22 — Схема данных, очереди менеджера (апрув публикует проект)

**Status:** ready-for-agent

- [ ] `GET /api/v1/projects/registry` — общий реестр: только `published` проекты, карточка (имя, УГТ, радар, категория, бюджет, организация), все роли
- [ ] Фильтры: `ugt_min`/`ugt_max`, область технологии (category), бюджет (min/max)
- [ ] `?ugt_min=7` — режим «реестр технологий» (тот же эндпоинт, без новой таблицы)
- [ ] Черновики/отклонённые исключены из реестров (видны только владельцу и менеджеру через свои эндпоинты)
- [ ] Тесты: апрувнутый проект в реестре, УГТ 7+ → в реестре технологий, фильтры работают, черновик не светится
