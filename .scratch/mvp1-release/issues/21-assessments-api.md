# 21 — API экспресс-оценки УГТ (черновик из любого ЛК)

**What to build:** Эндпоинты экспресс-оценки: любой пользователь (любая роль) из своего ЛК запускает оценку УГТ своего проекта → отвечает на визард → система считает предварительный УГТ (радар) → создаётся проект-**черновик** (владелец — оценивавший) с предварительным уровнем и ответами в `questionnaire_results`. Переоценка уже созданного проекта запрещена (403). Свои оценки/черновики видны владельцу; в реестрах черновики не светятся.

**Blocked by:** 20 — Схема данных нового ядра

**Status:** ready-for-agent

- [ ] `POST /api/v1/assessments` — принять ответы опросника (9 уровней × 4 категории), вычислить предварительный УГТ, создать проект со статусом черновик + `preliminary_level`, сохранить ответы в `questionnaire_results`
- [ ] `GET /api/v1/assessments/mine` — список своих оценок/черновиков для любой роли
- [ ] Повторная оценка существующего проекта (`current_level > 0` или уже создан через флоу) → 403 с понятным сообщением («переоценка недоступна — доработка уровнями N→N+1»)
- [ ] RBAC: черновик виден только владельцу и менеджеру ЦНТР
- [ ] Тесты: создание черновика через оценку, расчёт уровня, 403 на переоценку, изоляция чужих черновиков
