# 02 — Маршрут развития в карточке проекта

**What to build:** блок «Следующий шаг», превращающий карточку проекта в маршрут до следующего УГТ.

**Blocked by:** 01 — Контракт следующего действия проекта

**Status:** ready-for-agent

- [ ] Показаны два типа УГТ без смешения, следующая цель, прогресс, блокеры, ответственный и дата.
- [ ] Не более одного главного CTA, ведущего к разрешённому действию.
- [ ] Три темы и mobile поддержаны.
- [ ] Loading/empty/error состояния честны, без моков.

**Demo:** владелец одним кликом переходит к отсутствующим документам; менеджер видит своё разрешённое действие.

**Required tests:** все состояния контракта; единственный primary CTA; фокус; mobile 360 px; три темы.

**Do not build:** отдельный мастер данных, дублирующий существующие разделы проекта.
