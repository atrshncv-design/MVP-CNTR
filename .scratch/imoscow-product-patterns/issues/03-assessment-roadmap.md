# 03 — Результат оценки как дорожная карта

**What to build:** результат теста, объясняющий оценку и ведущий к следующему шагу.

**Blocked by:** 01 — Контракт следующего действия проекта

**Status:** ready-for-agent

- [ ] Показаны предварительный УГТ, официальный автоматический уровень, критерии и блокеры следующего уровня.
- [ ] Для оценки выше 2 явно показана необходимость документов и менеджера.
- [ ] Результат сохраняется в новый или существующий проект без повторного теста.
- [ ] Расчёт и объяснение детерминированы, без ИИ.

**Demo:** тест даёт предварительный УГТ 5, показывает официальный максимум УГТ 2, блокеры УГТ 3 и сохраняет результат в проект.

**Required tests:** оценки 1/2/3/9; anonymous/auth; отсутствие дубля при повторном сохранении; reload.

**Do not build:** новое правило расчёта УГТ или генеративные рекомендации.
