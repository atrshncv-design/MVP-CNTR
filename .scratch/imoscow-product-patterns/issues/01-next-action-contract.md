# 01 — Контракт следующего действия проекта

**What to build:** единое серверное представление следующего шага для ЛК, карточки проекта и менеджерской очереди.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Все состояния возвращают подтверждённый/предварительный УГТ, цель, прогресс, ответственную сторону, пояснение и допустимое действие.
- [ ] Используются существующие источники данных без параллельных статусов.
- [ ] Закрытые документы и служебные комментарии не раскрываются.
- [ ] Контрактные тесты покрывают весь жизненный цикл заявки.

**Demo:** проекты в состояниях «сбор документов», «на проверке», «доработка» и «подтверждено» получают разные корректные следующие действия.

**Required tests:** таблица переходов; RBAC владельца/участника/менеджера/посетителя; отсутствие N+1-запросов; обратная совместимость API.

**Do not build:** новый workflow engine, AI-определение действий или второй справочник статусов.
