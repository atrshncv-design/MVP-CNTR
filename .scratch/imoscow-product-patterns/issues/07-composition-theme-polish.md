# 07 — Композиционный проход по референсу i.moscow

**What to build:** единый визуальный проход с модульными карточками, ясной иерархией и действиями без копирования бренда.

**Blocked by:** 02, 03, 04, 05, 06

**Status:** ready-for-agent

- [ ] Один главный CTA на смысловой блок, вторичные действия подчинены.
- [ ] Единая иерархия на лендинге, результате, карточке проекта и в реестре.
- [ ] Сохранены синяя айдентика и три темы; изумрудный не введён как бренд-цвет.
- [ ] Удмуртский орнамент не ухудшает читаемость.
- [ ] Visual/accessibility smoke выполнен для тем и viewport.

**Demo:** маршрут лендинг → результат → проект → реестр сохраняет иерархию во всех темах.

**Required tests:** visual regression; WCAG AA; reduced motion; отсутствие horizontal scroll; печать/скриншот результата.

**Do not build:** четвёртую изумрудную тему, редизайн с нуля или копию i.moscow.
