# 06 — Ссылочные фильтры реестра

**What to build:** фильтруемый реестр, состояние которого воспроизводится по ссылке.

**Blocked by:** 05 — Доказательные карточки реестра

**Status:** ready-for-agent

- [ ] УГТ, отрасль, регион, организация, потребность, статус, поиск, сортировка и пагинация поддержаны.
- [ ] Фильтры отражаются в URL и восстанавливаются после открытия ссылки.
- [ ] Сервер фильтрует только по подтверждённому УГТ с нужными индексами.
- [ ] Активные фильтры видимы и сбрасываются по одному/все.
- [ ] Нагрузочный smoke соответствует базовым нормативам.
