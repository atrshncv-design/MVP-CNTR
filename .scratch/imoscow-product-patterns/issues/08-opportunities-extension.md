# 08 — P1-точка расширения каталога возможностей

**What to build:** возможность позже связать УГТ с услугами Центра без имитации неутверждённого каталога.

**Blocked by:** 01 — Контракт следующего действия; 07 — Композиционный проход

**Status:** ready-for-agent

- [ ] Минимальная модель содержит цель, диапазон УГТ, ограничения, оператора, доступность и регламент.
- [ ] Пустой каталог не показывает выдуманные услуги и тупиковые CTA.
- [ ] Расширение не усложняет P0-маршрут.
- [ ] Тикет запускается только после зелёного ближайшего release gate.

**Demo:** тестовая возможность видна подходящему проекту и скрыта от неподходящего; пустой каталог честен.

**Required tests:** диапазоны УГТ; отрасли; inactive; отсутствие регламента; публичные/служебные поля.

**Do not build:** реальные меры поддержки без утверждения Центром, AI-рекомендации, финансирование или платежи.
