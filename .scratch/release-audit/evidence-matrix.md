## 3. Генерация документов (ТЗ / Паспорт / ТЭО)

- **Сквозная механика существует**, но по решению спеки release-audit («Генерация документов скрывается/отключается и не считается готовой») и отсутствию маркера «В разработке» в UI:
- **Вердикт: PARTIAL → НЕ считается готовой.** Рекомендация: скрыть кнопки генерации в карточке проекта или пометить секцию «В разработке» (решение в тикетах 03/04 baseline-сборки); backend-endpoint можно оставить (покрыт тестом), но не афишировать в UI.

## 4. AI/RAG-доступ

- **Канал:** `/chat` → `process_chat` → `build_rag_context` → `rag.search_documents` (только таблица `rag_documents`: ГОСТы (456 чанков) + шаблоны tz/passport/teo + метаданные). 
- **Read-only:** `process_chat` не пишет в проекты/УГТ/требования; при ошибке провайдера — fallback-ответ без влияния на платформу.
- **Защита:** пользовательские проекты, документы, файлы и НИОКТР-карточки в контекст LLM НЕ попадают (в `search_documents` запрос идёт только по `rag_documents`). Внешний LLM получает только фрагменты базы знаний платформы.
- **Ограничения:** rate-limit на пользователя (429, `ai_metrics.allow_request`); метрики AI in-memory (не персистентны).
- **Вердикт: PASS** — справочный слой изолирован от пользовательских данных.
