# SPEC — Внутренний UX-контур

Переработать все экраны после входа в единый современный технологичный кабинет.

- Шапка: логотип, «Рабочий стол», «Проекты», «Заявки», «Больше функций», уведомления, профиль, выход.
- «Больше функций» — dropdown-сетка карточек с иконкой и названием; click/outside-click/Escape.
- Desktop: широкая рабочая область и сворачиваемые боковые панели. Mobile: логотип + кнопка меню.
- Единый стиль для всех ролей, средняя плотность, контрастная типографика.
- Списки: table/cards toggle, поиск, фильтры, сортировка, пагинация, сохранение фильтров.
- Проекты, организации и специалисты раскрываются на отдельных подробных страницах.
- Компактные карточки без радаров и длинного текста. Радар — боковой блок страницы проекта.
- Проект: сводка → статус/УГТ → документы → команда → история → аналитика.
- Обязателен breadcrumb. Все функции имеют реальный результат или «В разработке».

Не менять baseline `c4f0794` и localhost:3000; integration проверять на 3001/3002. Не ослаблять RBAC/IDOR.
