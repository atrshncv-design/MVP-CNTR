# Спецификация: временно скрыть AI-функции из UX/UI (серверная версия)

## Задача

На серверной версии пользователи видят AI-функции (AI-ассистент, ИИ-консультант
по документам, подбор партнёра с LLM-бейджами), которые пока не должны
светиться в интерфейсе.

## Решение

Скрыть все три AI-поверхности за флагами, код и API не удалять:

1. **AI-ассистент** — пункт верхнего меню скрыт (`AI_UI_ENABLED=false`
   в `src/lib/release.ts`); страница `/dashboard/ai-assistant` отдаёт
   заглушку «Раздел временно скрыт» вместо чата; матрица ролей не тронута
   (маршрут остаётся покрытым, fail-closed цел).
2. **Подбор партнёра** — пункт меню скрыт (`P2_MATCHING_ENABLED=false`,
   штатный kill-switch релиза); страница `/dashboard/matching` отдаёт
   заглушку вместо `MatchingMode` (вместе с ней прячутся «ИИ подбирает…»,
   «Ошибка ИИ», eyebrow «ИИ-агент», LLM/fallback-бейджи). Исходники
   `features/matching/*`, `llm.ts`, `POST /match` в api-client не тронуты.
3. **ИИ-консультант в карточке проекта** — `AiDocConsultant` в `ProjectCard`
   не монтируется при `AI_UI_ENABLED=false`.
4. Словари `ru/en/zh` не тронуты (ключи остаются для возврата, в UI не
   используются, пока скрыты точки входа).

Возврат: `AI_UI_ENABLED=true` + `P2_MATCHING_ENABLED=true` (+ вернуть пункты
в `CORE_NAVIGATION` автоматически через флаги).

## Решения по реализации

- Флаги в `src/lib/release.ts` (рядом с `P2_*`): `AI_UI_ENABLED=false`.
  Почему там: единый модуль границ релиза, тесты уже читают его.
- Условный спред в `CORE_NAVIGATION` (`...(FLAG ? [...] : [])`) — тот же
  приём, что уже используется для matching.
- Заглушки страниц — через серверный словарь (`dashboard.aiHiddenTitle/Desc`?
  нет — переиспользуем существующие ключи без AI-текста, чтобы не плодить
  ключи; если нейтрального ключа нет — короткий клиентский stub без
  обращения к AI-словарям). Точнее: stub — отдельная ветка в page.tsx,
  видимого AI-текста нет.
- `ProjectCard`: `{AI_UI_ENABLED && <AiDocConsultant .../>}`.
- Тесты: `ui-shell` → assert отсутствия пункта; `p2-gating` → assert
  закрытого состояния (`P2_MATCHING_ENABLED === false`, пункта нет в layout).

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `lib/release` | kill-switches релиза | `AI_UI_ENABLED`, `P2_MATCHING_ENABLED` | — |
| `dashboard/layout` | состав верхнего меню | `CORE_NAVIGATION` (условно) | фильтрация по флагам |
| `ai-assistant/page`, `matching/page` | точка входа экранов | заглушка при выкл. флаге | чат / MatchingMode |

Швы для тестов: `npm test` (ui-shell, p2-gating, routes-matrix, matching —
источники не тронуты, зелёные).
