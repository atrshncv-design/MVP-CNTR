## Критерии приёмки

- [ ] `ProjectCard` разбит: `UgtLine`, `ChecklistPanel`, `CanvasBlocks`, `DocsPanel`, `TeamPanel`, `ActionsPanel`, `HistoryPanel`. Монолит `project/[id]/page.tsx` <300 строк обвязки, логика в features. Тест UgtLine: при УГТ 5 и 7 StageRequirement секторов 7, прогресс 3/7 = 3 закрашено цветом --tz-ugt-5
- [ ] `UgtLine` рендерит 9 уровней линейно, текущий подсвечен, дробные сектора — маленькие деления внутри уровня, тултип «Документ: ПМИ (14 с.) — загружен», берёт число секторов из `GET /gost-requirements?level` или fallback StageRequirement
- [ ] `CanvasBlocks` показывает 15 полей канвы по условию уровня (архитектура скрыта на УГТ1, предтребования скрыты на УГТ1, УГТ9 + блок дальнейших планов). Поля редактируемы только если `status===draft` или роль в {manager,admin,lead}, иначе disabled + подсказка «Только загрузка документов»
- [ ] `ChecklistPanel` — список обязательных доков для перехода current→next с галочками, кнопка «Скачать шаблон» per requirement, интеграция с DocsPanel (загруженный док гасит галочку)
- [ ] `ActionsPanel` внизу: владелец/manager/admin — Редактировать/Опубликовать/Архивировать/Экспорт/Токен/Поделиться; остальные — Загрузить документ + Поделиться; beforeunload диалог + автосохранение 30с индикатор «Сохранено», история AuditTrail всем видна, при No-Go бейдж «Возврат на УГТ N + причина», скачивание через `GET /files/{id}/download`, типы PDF/DOCX/XLSX/JPG/PNG 25МБ, ClamAV 409/413 обработка
- [ ] Мультитеги 1-5 из справочника 30+ в шапке/форме, бюджет виден всем, сортировка/дата не в карточке
