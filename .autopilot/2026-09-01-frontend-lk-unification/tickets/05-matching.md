# 05 — Matching отдельный режим (ИИ без ПДн, топ≤5 через ЦНТР)

**Требования:** R07, R23, G27-G29, G44, G57, R32, G56
**Blocked by:** 01
**Зона:** `src/features/matching/`, `src/app/dashboard/matching/`
**Волна:** 2
**Status:** ready

## Что должно заработать

Отдельный режим `/dashboard/matching` доступен всем 8 ролям (пункт в топбаре «Подбор партнёра»). Вход: выбрать свой проект (селект из `GET /projects` где участник) или описать идею текстом (textarea title+annotation). Доп. фильтры (опц.) регион/отрасль/УГТ. Запуск → POST /match с обезличенными полями (только title/annotation/теги/сектор/УГТ/регион/competencies, без ПДн, contour tuno) → retriever pg_trgm 20 → скоринг → топ≤5 (не строго 5) с причинами «совпадение компетенций (2: AI, медицина)» . Результат — карточки организаций/исполнителей платформы (только верифицированные, не внешние НИОКТР) с бейджем причины. Действие «Предложить через ЦНТР» → MatchRequest → Notification менеджеру/исполнителю. Состояния: нет данных → подсказка заполнить, недостаточно → «Заполните карточку», идёт анализ → прогресс, 0 → «Ничего не найдено — уточните / перейдите в реестр», слабые → «Более подходящих нет, вот ближайший», ошибка ИИ → Retry, устарел → «Требуется повторный запуск».

## Критерии приёмки

- [ ] Страница `/dashboard/matching` доступна всем 8 ролям (ROUTE_ALLOWED_ROLES), пункт в топбаре «Подбор партнёра» виден всем, middleware не блокирует. Форма: селект «Мои проекты» (из api-client.getProjects) + textarea «Опишите идею» + фильтры регион/отрасль/УГТ (опц.) + кнопка «Подобрать»
- [ ] Запуск шлёт `POST /match` только с чистым payload `{title, annotation, sector, ugt_level, region, competencies}` без email/ФИО/бюджета, логи обезличивания, contour tuno. Проверено: в запросе нет `user.email` или `organization` ПДн
- [ ] Результат рендерит ≤5 карточек с `score` не показывается числом, только ранжирование + список `reasons` per match («совпадение компетенций (2: AI)», «регион Удмуртия»). Карточки — только верифицированные организации/исполнители платформы (`Organization`/`executors/specialists`), не внешние НИОКТР. Кнопка «Предложить через ЦНТР» → `POST /requests` или `Notification` (мок если нет эндпоинта — toast «Заявка отправлена в ЦНТР»)
- [ ] Состояния: нет проекта и пустое описание → empty «Выберите проект или опишите идею»; недостаточно данных → «Заполните карточку проекта»; идёт анализ → спиннер + «ИИ подбирает партнёров»; 0 → empty «Ничего не найдено — уточните описание / перейдите в реестр» + fallback ссылка; слабые → баннер «Более подходящих вариантов сейчас нет, вот ближайший»; ошибка → «Ошибка ИИ — повторить»; устарел → «Результат устарел — запустить заново» с кнопкой
- [ ] Доступность: фильтр tags мультитеги 1-5 из того же справочника 30+, пагинация не нужна (≤5), realtime не нужен, тесты matching mock

## Технические заметки

- Использовать существующий `app/services/matching.py` и `POST /match` — фронт не изобретает скоринг, только обезличивание
- Зона только matching — не лезть в registry/project
- Если бэк POST /match требует auth — слать Bearer, иначе 401 → модалка сессии (из 07)
- Тест: обезличивание — snapshot запроса не содержит ПДн
