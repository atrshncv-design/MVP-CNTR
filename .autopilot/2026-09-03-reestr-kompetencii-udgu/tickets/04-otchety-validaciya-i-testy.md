## Что должно заработать

Пайплайн доводится до «показательного» уровня: отчёт `report.md` человекочитаем и отвечает на вопросы «что выгрузили, чего не хватает, что в сырых файлах, что в Wave2», дедупликация и валидация диапазонов (B-Tree) работают, маппинг на реестры платформы документирован, тест-сьют полный, пример архива прогоняется end-to-end. После таска ЦНТР может вручить Кашину готовый комплект и сам прогнать любой его ZIP за 10 секунд.

## Критерии приёмки

- [ ] `report.md` — содержит: заголовок `Отчёт по выгрузке УдГУ YYYY-MM-DD`, таблицу заполненности по разделам `%` (R21), список пустых разделов, список проиндексированных `raw/` файлов с количеством (R16), ошибки по строкам с человекочитаемыми сообщениями, раздел `Wave2 — что доделать` и `raw_refs` сводку; `report.json` — машинная копия тех же данных
- [ ] Дедуп: архив с двумя строками оборудования с одинаковым `(название+год)` → в `udgu_import.json` одна запись + warning `дубликат 04 строка 5 и 6 объединены`; валидация диапазонов: год `3026` → warning `год ожидается 1900-2026`; лимит 10k строк: лист с 10001 строкой → warning `превышен лимит 10k, обработано 10000`
- [ ] `docs/udgu_template/mapping.md` — таблица маппинга полей шаблона на модели платформы (`organizations`, `competencies`, `equipment`, `patents`, `services`, `people`) с примером JSON-фрагмента до/после; `README_УдГУ_выгрузка.md` дополнен разделом «Что будет после выгрузки» (верификация ЦНТР → заливка)
- [ ] Расширяемость: добавлена папка `08_доп_тип/` + лист `08_доп_тип` в копию example → пайплайн без изменения кода индексирует файлы и кладёт строки в `extra_sections["08_доп_тип"]` (тест)
- [ ] Тесты `tests/test_udgu_e2e.py` — end-to-end: берёт `example/УдГУ_...zip`, прогоняет `ingest.py`, проверяет `udgu_import.json` валиден, `report.md` содержит все секции, `warnings.log` существует; `uv run pytest -q -k udgu` — все 3 сьюта зелёные (schema+template+ingest+e2e)
- [ ] Документация финальная: `docs/udgu_template/README_УдГУ_выгрузка.md` и `spec.md` непротиворечивы; `uv run ruff check` зелёный; повторный прогон `ingest.py` на том же ZIP идемпотентен (выход перезаписывается, не дублируется)
