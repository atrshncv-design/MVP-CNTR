## Что должно заработать

Финальная приёмка доказывает цифру вместо слов: прогон на 50 concurrent по порогам (≥99% успеха, API p95 ≤1с, страницы ≤2с, RAM <80%), ежедневный бэкап с restore-репетицией, доставка алертов в Telegram, явный список боевых блокеров (документы ПДн, offsite, секреты владельца). Итог — обновлённый отчёт с трассировкой каждой цифры.

## Критерии приёмки

- [ ] Нагрузочный прогон на 50 concurrent соответствует всем четырём порогам
- [ ] Принудительный бэкап даёт дамп, базу, зеркало MinIO и валидные чексуммы; restore-репетиция воспроизводит данные
- [ ] Синтетический алерт доходит до Telegram
- [ ] Боевые блокеры перечислены явно: документы ПДн, offsite-хранилище, секреты владельца
- [ ] Отчёт обновлён; каждая цифра трассируется к замеру, лимиту или ответу
