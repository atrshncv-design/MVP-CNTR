## Что должно заработать

Импорт индексирует только `ГОСТ*.pdf` из папки «Трансфер технологий» по явному allowlist (deny-by-default). Внутренние документы — интервью, roadmap, код, отчёты, доступы, проектные `docs/` — исключены. Импорт пишет хеш-манифест; исходные PDF в git не коммитятся.

- [ ] Импорт берёт только allowlist `ГОСТ*.pdf`; ZIP, DOCX и повреждённые копии отбрасываются
- [ ] Файлы вне allowlist никогда не попадают в индекс и во внешний запрос
- [ ] Хеш-манифест воспроизводим; повторный импорт без изменений — no-op
- [ ] Secret-scan импорта чист; секреты только именами
