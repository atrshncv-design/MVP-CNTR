# 05 — Честные лимиты и закрытый реестр специалистов

**Требования:** R05i (истории 9, 11)
**Blocked by:** —
**Зона:** `backend/registry`
**Волна:** 1
**Status:** ready

## Что должно заработать

Повышенный лимит реестров — только за валидный токен: поддельный заголовок
оставляет anon-лимит. Реестр специалистов не отдаёт массовый дамп ПДн
анониму: либо авторизация, либо пагинация с жёстким лимитом и rate-limit.

## Из брифа, дословно

> составь спеку и тикеты для внесения правок
> «Всё + приоритеты»: спека покрывает все подтверждённые находки; таски — на Blocker/Critical/High/CI (Дополнения 2026-09-08)

## Разделы спецификации

Истории 9, 11, Решение §5, Границы `registry`.

## Критерии приёмки

- [ ] Заголовок Authorization без валидного токена оставляет anon-лимит (флуд режется)
- [ ] Валидный токен даёт auth-лимит; классификация покрыта тестом
- [ ] Анонимный запрос специалистов → 401 либо ≤100 записей с пагинацией и rate-limit
- [ ] Полная выборка без LIMIT закрыта на всех списках реестра
- [ ] Тест на шве HTTP покрывает обход лимита и дамп ПДн
