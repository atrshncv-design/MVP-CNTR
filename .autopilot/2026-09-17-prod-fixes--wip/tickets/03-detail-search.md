## Что должно заработать

У реестров появляются детальные страницы по URL (проект, организация по
ОГРН, НИОКТР по регномеру; мусор — 404). Поиск ищет по всей базе на сервере,
а не по загруженному. Карточка проекта в витрине показывает описание
и статус (API начинает их отдавать).

## Из брифа, дословно

> «Как видишь реализацию?» (деталки, поиск, поля карточек — из разбора интервью)

## Разделы спецификации

Истории 5–7, Решения §1–§3, границы `registry-api`.

## Критерии приёмки

- [ ] Публичные деталки: проект/организация/НИОКТР по URL, 404 на мусор, без токена
- [ ] Серверный поиск находит то, что не загружено в браузер
- [ ] `RegistryProjectOut` отдаёт описание и статус; витрина их показывает
- [ ] Фронт-деталки (отдельный малый diff в `(landing)/`) открывают те же URL
- [ ] Тесты ручек + зелёные сьюты
