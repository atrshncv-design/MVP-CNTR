## Что должно заработать

В карточке проекта — кнопки «ТЗ / Паспорт / ТЭО», документ создаётся
реальным эндпоинтом генерации и скачивается. Кнопка «скачать шаблон»
отдаёт серверный шаблон: либо чинится вызов несуществующего
`GET /api/v1/templates/{id}` (сверка с бэкендом), либо правится на
существующие ручки шаблонов — решает исполнитель, разрыв один.

## Из брифа, дословно

> генерация отчётов: бэкенд есть, кнопок в UI нет (из разбора интервью)

## Разделы спецификации

Истории 10–11, Решения §5, границы `generation`.

## Критерии приёмки

- [ ] Три кнопки создают и отдают документы (200, черновик сохранён, аудит писан)
- [ ] Шаблон качается с сервера без пометки BLOCKED
- [ ] Нет прав — 404-маскировка, чужой проект недоступен
- [ ] Тесты пути + зелёные сьюты
