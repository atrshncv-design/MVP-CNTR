# 01 — Создание проектов исполнителем

**Требования:** R02, R02.1
**Blocked by:** —
**Зона:** `technozrelost-frontend/src/app/dashboard/`
**Волна:** 1
**Status:** done

## Что должно заработать

Исполнитель заходит в свой кабинет и создаёт проект той же анкетой УГТ,
что видит заказчик. Если организация не подтверждена — понятная подсказка,
а не молчаливый отказ. Созданный проект проходит ту же модерацию публикации
(УГТ 1–2 сами, 3–9 через менеджера).

## Из брифа, дословно

> «реестр проектов работает, а создание проектов в ЛК?»

## Разделы спецификации

Истории 1–2, границы `project-create`.

## Критерии приёмки

- [ ] В кабинете исполнителя есть страница создания проекта (201 на `POST /projects`)
- [ ] Неподтверждённая организация даёт читаемую подсказку
- [ ] Проект исполнителя публикуется по тем же правилам, попадает в публичный реестр
- [ ] Сборка фронта зелёная, существующие кабинеты не сломаны
