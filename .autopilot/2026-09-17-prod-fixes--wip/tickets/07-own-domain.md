## Что должно заработать

Механизм переезда на собственный домен: выпуск сертификата на новое имя
тем же ACME-процессом, переключение адресов окружения, редирект со старого
имени на новое, операторская инструкция (покупка имени — за владельцем,
в тикете имя-плейсхолдер + проверка формата). Причина переезда фиксируется:
репутационные фильтры операторов к wildcard-DNS.

## Критерии приёмки

- [ ] Переключение адресов — одной переменной окружения, без правок кода
- [ ] Сертификат выпускается/продлевается на новое имя тем же процессом
- [ ] Старое имя редиректит на новое (301), гейт принимает оба формата
- [ ] Инструкция для владельца: купить имя → вписать → сообщить → перезапуск
- [ ] Тесты гейта на оба формата зелёные
