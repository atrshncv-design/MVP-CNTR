# 03 — Закрытая выдача привилегированных ролей

**Требования:** R04i (истории 6, 7)
**Blocked by:** —
**Зона:** `backend/auth`
**Волна:** 1
**Status:** ready

## Что должно заработать

Саморегистрация выдаёт только непривилегированные роли по явному allowlist;
роли auditor/regulating_organization/investor назначает только администратор;
ранее самозарегистрированные привилегии отозваны миграцией данных; чужие
контрольные точки недоступны для решения посторонним.

## Из брифа, дословно

> составь спеку и тикеты для внесения правок
> «Всё + приоритеты»: спека покрывает все подтверждённые находки; таски — на Blocker/Critical/High/CI (Дополнения 2026-09-08)

## Разделы спецификации

Истории 6–7, Решение §3, Границы `auth`.

## Критерии приёмки

- [ ] `POST /auth/register` с ролью auditor/regulating_organization/investor → 403
- [ ] Назначение привилегированной роли работает только через администратора
- [ ] Миграция отзывает ранее самозарегистрированные привилегии (проверено на фикстуре)
- [ ] Чужой PATCH control-points посторонним → 403/404; матрица доступов покрыта тестом
- [ ] Аудит фиксирует выдачу/отзыв привилегированной роли
- [ ] Тест на шве HTTP покрывает регистрацию, назначение и решение КТ
