## Что должно заработать

Страница проектов лендинга показывает данные публичного реестра, а не
захардкоженную demo-витрину; пустой реестр даёт честное пустое состояние,
а не выдуманные карточки.

## Из брифа, дословно

> составь спеку и тикеты для внесения правок
> «Всё + приоритеты»: спека покрывает все подтверждённые находки; таски — на Blocker/Critical/High/CI (Дополнения 2026-09-08)

## Разделы спецификации

История 18, Границы `landing`, `registry`.

## Критерии приёмки

- [ ] Карточка на лендинге соответствует проекту, созданному через API
- [ ] Demo-массив удалён из бандла; заглушка нигде не импортируется
- [ ] Пустой реестр → пустое состояние с призывом к действию, без выдуманных данных
- [ ] Пагинация витрины не ломается на границе страниц
- [ ] Тест покрывает витрину из живых данных и пустое состояние
