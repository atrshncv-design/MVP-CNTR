# 10 — Offline-очередь без секретов и потерь

**Требования:** R05i (история 21)
**Blocked by:** —
**Зона:** `frontend/offline`
**Волна:** 2
**Status:** ready

## Что должно заработать

Очередь хранит действия без заголовка Authorization: токен подставляется
из сессии в момент отправки; параллельно добавленные во время синхронизации
действия не теряются при перезаписи очереди.

## Из брифа, дословно

> составь спеку и тикеты для внесения правок
> «Всё + приоритеты»: спека покрывает все подтверждённые находки; таски — на Blocker/Critical/High/CI (Дополнения 2026-09-08)

## Разделы спецификации

История 21, Решение §4, Границы `frontend-auth`.

## Критерии приёмки

- [ ] В localStorage очереди нет строки `Bearer` после постановки действия
- [ ] Синхронизация уходит с актуальным токеном сессии и доходит до API
- [ ] Действие, добавленное во время sync, сохраняется (слияние по id)
- [ ] Тест покрывает хранилище без секретов и конкурентный enqueue
