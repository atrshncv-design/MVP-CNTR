# Архив Autopilot

Здесь хранятся завершённые прогоны. Они исключены из обычного поиска через
корневой `.ignore`, чтобы старые требования не подмешивались в текущую работу.

- `runs/` — завершённые прогоны Autopilot по датам.
- `dorozhnaya-karta-020926-011227/` — служебная запись отдельного прогона дорожной карты.

Открывайте конкретный прогон только по явному пути. Текущий или последний прогон
остаётся непосредственно в `.autopilot/` вместе с `state.js` и дашбордом.
