# Границы и правила прогона `registry-limits-env` (ярус T0)

Прогон в одном контексте — публичных сигнатур между исполнителями нет.

## Правила проекта

- Стек: Python + FastAPI. Рабочая папка: `technozrelost-backend/`.
- Команды: `uv run pytest -q` (нужна БД — поднята); один файл — `uv run pytest <путь> -q`. Голый `uv sync` запрещён.
- Не трогать: frontend; логи, сиды, фикстуры; алгоритмические константы.
- `.env.example` — только имена, без значений.

## Швы

1. Чтение лимитов из `settings` + существующий тест лимита реестра.
2. Зелёная сюита бэкенда.
