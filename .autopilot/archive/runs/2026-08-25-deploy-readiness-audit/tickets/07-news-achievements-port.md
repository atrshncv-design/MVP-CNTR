## Что должно заработать

Фронтенд платформы (уже содержащий страницы новостей и достижений) получает работающий API: `/api/v1/news*` и `/api/v1/achievements*` отвечают из каноничного бэкенда `technozrelost-backend`. Модули перенесены из старой линии (корневой `app/`), миграции переоформлены под нумерацию платформы, HTML-контент санитизируется единым `html_sanitizer`.

- Тесты: портировать/адаптировать тесты источников; каждый эндпоинт покрыт; `uv sync --extra dev && uv run pytest -q` зелёный.
