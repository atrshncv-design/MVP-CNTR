# Спецификация: Вынос P0-хардкода фронта в словари

## Задача

Интерфейс платформы нельзя полностью перевести: строки зашиты прямо в экраны мимо словарей, и каждая новая страница копирует этот приём. Пользователь-валидатор хочет, чтобы английский интерфейс стал полным — без русских остатков на экране, в экспорте и в справочниках.

## Решение

После прогона весь P0-хардкод фронта живёт в словарях двух локалей: экраны берут тексты через перевод, контентные данные и заголовки экспорта — тоже, повторный прогон сканера показывает ноль строк экрана вне словарей, а переключение локали даёт полностью английский интерфейс.

## Решения по реализации

- Вариант выноса — существующие словари next-intl, ключи по неймспейсам фич. Почему так: инвариант репозитория (пользователь подтвердил объём и способ в брифинге).
- Живой словарь — пара в каталоге исходников (её грузит серверная конфигурация локали в проде); вторая пара зеркалится один в один. Почему так: конфигурация читает первую с fallback на вторую, тесты смотрят обе — расхождение роняет тесты.
- Контентные данные (методология, витрина, метки отраслей) — неймспейсами в те же словари. Почему так: отдельный механизм локализации контента — новая возможность, а не вынос.
- Строки с подстановками — через параметры перевода, а не склейку. Почему так: склейка ломает порядок слов в английском.
- Списки ключевых слов для обезличивания и логи — не трогаем. Почему так: это рабочее тело функции, а не отображаемый текст (аудит P1-2).
- Волны — по фичам поверх чекпоинта, словарь — общий ресурс: ключи вносит каждый таск в своей зоне, дубли ключей запрещены. Почему так: иначе параллельные таски перепишут друг другу словарь.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `dictionaries` | ключи обеих локалей, паритет | `t(неймспейс.ключ[, параметры]) -> строка` | файлы словарей, fallback-цепочку |
| `screens/project` | экраны проектного контура | экраны без литералов | какие ключи за каким текстом |
| `screens/registry` | реестр, фильтры, экспорт | таблица и файл без литералов | то же |
| `screens/dashboard` | дашборд и общие панели | панели без литералов | то же |
| `screens/misc` | лендинг, регистрация, контентные данные | страницы и справочники без литералов | то же |

Швы для тестов — два, и оба обязательные: counts сканера (строки экрана вне словарей — ноль, паритет ключей — ноль) и зелёная сюита фронта (линт + тесты). Spot-проверка EN-локали — глазами приёмки, не таском.
