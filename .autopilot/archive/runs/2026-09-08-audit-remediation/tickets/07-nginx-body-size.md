# 07 — Лимит тела запроса на балансировщике под загрузки

**Требования:** R05i (история 16)
**Blocked by:** 04
**Зона:** `infra/nginx`
**Волна:** 2
**Status:** ready

## Что должно заработать

Легитимный файл ровно 25 МБ проходит через прод-балансировщик (201),
лимит тела покрывает файл плюс multipart-накладные расходы; единый
источник лимита не даёт им разъехаться снова.

## Из брифа, дословно

> составь спеку и тикеты для внесения правок
> «Всё + приоритеты»: спека покрывает все подтверждённые находки; таски — на Blocker/Critical/High/CI (Дополнения 2026-09-08)

## Разделы спецификации

История 16, Решения §1, §10, Границы `files`, `infra-observe`.

## Критерии приёмки

- [ ] Файл ровно 25 МБ через балансировщик → 201, а не 413
- [ ] Файл сверх лимита по-прежнему отклоняется внятным статусом
- [ ] Лимиты бэкенда и балансировщика сверяются из одного источника/теста
- [ ] Тест на шве HTTP покрывает граничный размер через прокси-конфиг
