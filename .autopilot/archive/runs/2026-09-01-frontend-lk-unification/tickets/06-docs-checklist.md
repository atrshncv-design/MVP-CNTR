## Что должно заработать

На каждом УГТ чек-лист обязательных документов для перехода (из ГОСТ Р 58048-2017 / StageRequirement), шаблоны для скачивания, загрузка только PDF/DOCX/XLSX/JPG/PNG 25МБ с ClamAV fail-closed (409 pending/413 oversize), только скачать (без превью), ИИ-консультант узкий отвечает только про документы/шаблоны текущего УГТ без ПДн. Дубли блоков документов в карточке унифицированы в один `DocsPanel`.

## Из брифа, дословно

> «на каждом УГТ у него должен быть список обязательных документов для перехода на новый. В идеале шаблоны для заполнения... интегрировать ИИ-агента консультанта по документам, чтобы мог спросить только про документы для УГТ»
> «У нас предусмотрены разные ИИ-агенты под разные задачи. Это просто одна из задач»
> «Только скачать»
> «PDF/DOCX/XLSX/JPG/PNG 25МБ»

## Критерии приёмки

- [ ] `GostChecklist` берёт список требований из `GET /gost-requirements?level` (или fallback `GET /projects/{id}/stage-requirements` или мок из RAG), рендерит чек-лист с галочками per StageRequirement, рядом кнопка «Скачать шаблон» (генерирует пустой PDF/DOCX по template_version). Число чеков = числу минисекторов в UgtLine (история 10)
- [ ] `DocsPanel` унифицирован: один блок вместо 3 дублей, список загруженных `ProjectDocument` с `title, version, uploaded_by, scan_status`, кнопка «Загрузить документ» → file input accept `.pdf,.docx,.xlsx,.jpg,.png` 25МБ, ошибка «Файл >25МБ» 413, «Проверка антивирусом» 409 с retry «Перепроверить», только кнопка «Скачать» → `GET /files/{id}/download`, без `setViewingDoc({content: url})`
- [ ] `AiDocConsultant` виджет в карточке (drawer/modal) принимает вопрос, шлёт `POST /chat` или `POST /rag/search` с обезличенным контекстом `level + requirement codes` без ПДн, отвечает только про доки/шаблоны, на общие вопросы отвечает «Я консультирую только по документам УГТ». Проверено: в payload нет ПДн
- [ ] Загрузка: drag-n-drop + прогресс, валидация mime + size до отправки, после успеха чек-лист гасится, UgtLine сектор закрашивается. Использует `api-client.uploadFile`, `file_storage` fail-closed сохранён
- [ ] Тест: чек-лист 5 доков → 5 секторов, загрузка 1 дока → 1/5 закрашено, ИИ payload без ПДн
