## Что должно заработать

Каждый эндпоинт API закрыт проверкой доступа согласно матрице ролей; аутентификация выдерживает базовый натиск; инъекции исключены использованием ORM; загрузка файлов проверяется (тип + антивирус); злоупотребления ограничены (rate limit, размеры запросов). Внешние вызовы LLM устойчивы: таймауты, обработка недоступности, секреты не попадают в логи.

## Чек-лист аудита

- Матрица authZ: все роутеры × роли (9 ролей) — чужой/анонимный доступ отвергается; регресс-тесты на критичные запреты
- JWT/python-jose: алгоритм (без `none`), срок жизни, проверка подписи; passlib/bcrypt без ослаблений
- Сырой SQL: поиск текстовых SQL-запросов вне ORM; `eval`/`exec`/`pickle`
- Файлы: тип/размер, прохождение через ClamAV (или фикс пробела), пути сохранения (без path traversal)
- Rate limiting, лимит тела запроса, поведение при неверном логине (одинаковое сообщение, задержка)
- DEBUG-режим, детальные ошибки наружу, stack traces в ответах
- LLM-API вызовы: таймаут, retry-политика, что логируется (без ключей), поведение при недоступности провайдера
- Зависимости: аудит известных CVE (pip-audit или аналог), критичное — обновить безопасно
