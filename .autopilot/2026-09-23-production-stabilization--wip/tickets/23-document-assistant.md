# 23 — Ассистент по документам

**Требование:** R33; дополняет R16/R26. **После:** T03/T04, T08/T14 и зелёного локального baseline.

Проверить путь `AiDocConsultant` → обезличивание → `/rag/search` и `/chat/kaba` → ответ с источниками. На утверждённом корпусе ГОСТов и синтетических вопросах ассистент должен отвечать по документам текущего УГТ, честно отказывать вне темы и при отсутствии релевантных источников, сохранять контур `kaba`, не передавать проектные данные/ПДн провайдеру. Ошибки и отсутствие ключа дают понятный fallback. Начать с точных failing tests для подтверждённых дефектов; затем минимальный fix и focused regression. Проверить frontend/backend контракт и источники в UI. Live provider eval не запускать до нового ключа владельца; статус оставить BLOCKED, не симулировать успех. Исполнитель не меняет `.autopilot/**` и не коммитит.
