# 03 — Воспроизводимое frontend test/build environment (CODE-06)

**Требования:** R20, R21. **После:** T22 и повторного backend gate T02.
**Зона:** `technozrelost-frontend/` (только окружение).

## Цель

Установить зависимости строго по lock-файлу (`npm ci`) и получить честный baseline `npm test` и `npm run build`. Предыдущее состояние аудита: 171 passed, 38 import errors (`next-intl` отсутствовал), `next: command not found`; после установки определить, есть ли реальные тестовые или build-дефекты.

## Разрешено

- `npm ci` в stabilization worktree;
- чтение package/lock и тестовых команд;
- запуск `npm test`, `npm run build`;
- фиксация версий и точных результатов.

## Запрещено

Не менять `src/**`, существующие тесты, package/lock-файлы, `.autopilot/**`, production или пользовательские файлы. Исполнитель не коммитит. Если нужен ремонт кода или тестов, вернуть отдельный finding с воспроизведением.

## Приёмка

1. `npm ci` exit 0 и lock-файл без изменений.
2. `npm test` и `npm run build` выполнены без маскировки exit code.
3. CODE-06 получает `DONE` только при зелёных тестах и сборке; иначе `BLOCKED` или отдельный доказанный дефект.
4. Отчёт содержит версии Node/npm, команды, exit codes, число тестов и список конкретных блокеров.
5. Worktree не содержит продуктовых изменений от этого таска.
