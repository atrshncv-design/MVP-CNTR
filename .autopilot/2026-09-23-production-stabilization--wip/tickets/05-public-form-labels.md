# 05 — UX-01: доступные подписи публичных фильтров

**Требование:** R24 (часть UX-01). **После:** зелёных локальных backend/frontend-гейтов и общего CI baseline. **Зона:** только публичные фильтры `/projects` и `/roadmap`, узкий frontend-тест.

## Контекст и RED

Аудит `docs/audit/2026-09-21-production/09-final/findings.json` → `UX-01` (EV-019/EV-021): поиск `/projects` имеет placeholder, но не accessible name; две видимые подписи УГТ на `/roadmap` не связаны с `select`. Локальный код: `src/components/landing/projects-showcase.tsx` (`input type="search"`) и `src/components/landing/roadmap-content.tsx` (`UgtSelect`). Сначала проверить, что finding всё ещё воспроизводится в текущем коде, и добавить узкий failing regression check для трёх контролов.

## Изменение

- Поиску дать локализованное программное имя, не меняя placeholder, фильтрацию и видимый дизайн. Перед добавлением перевода проверить существующие ключи/паттерны, не переиспользовать ключ с неверным смыслом (`ariaSearch` сейчас «Категория»).
- В `UgtSelect` связать видимый `<label>` с `<select>` нативно; оба вызова (текущий и целевой УГТ) должны получить независимые идентификаторы или эквивалентную корректную связь.
- Не менять API, маршруты, метрики, backend, auth, данные, production и другие страницы. Не править `.autopilot/**`, не коммитить и не push'ить — это делает оркестратор.

## Приёмка

1. Для search `/projects` и двух `select` `/roadmap` доступное имя подтверждается тестом/DOM-проверкой; три контрола покрыты.
2. Клавиатурная работа и фильтрация не изменились; видимый дизайн без регрессии на 1920/768/375 px (при возможности — безопасные локальные screenshots без ПДн).
3. Focused regression, полный `npm run lint`, `npm test`, `API_URL_INTERNAL=http://backend:8000 npm run build -- --webpack` проходят; штатный Turbopack локально может оставаться sandbox-BLOCKED и так отмечается.
4. Отчёт исполнителя содержит diff, RED/GREEN evidence, ограничения проверки. Оркестратор выполняет независимое review, проверки, commit и push.
