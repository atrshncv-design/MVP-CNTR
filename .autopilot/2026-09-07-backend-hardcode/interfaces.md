# Границы и правила прогона `backend-hardcode`

## Границы, решённые в спецификации

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `errors` | коды, тексты ru/en, выбор по языку запроса | `raise_error(код[, параметры]) -> HTTPException с кодом в заголовке` | тексты каталога, разбор заголовка |
| `settings` | окружение-зависимые значения | `настройки с именами из .env.example` | парсинг окружения, дефолты |

## Контракт ошибок (общий для всех тасков)

- Тело `detail` — всегда строка (как раньше); стабильный код — в заголовке ответа.
- Язык — из заголовка запроса, умолчание русское (текущее поведение).
- Подстановки — параметрами каталога, никакой склейки в местах вызова.
- Ключи вида `AUTH_INVALID`; тексты ru+en пишет исполнитель, спорные — списком в контракт-блоке.

## Общие правила проекта

- Стек: Python + FastAPI (SQLAlchemy). Рабочая папка бэкенда: `technozrelost-backend/`.
- Команды (из `technozrelost-backend/`): `uv run pytest -q` (вся сюита, нужна БД — поднята), один файл — `uv run pytest <путь> -q`. Голый `uv sync` без `--extra dev` запрещён (сносит dev-зависимости).
- Бэкенд уже поднят локально (:8000) — пробы API живьём входят в приёмку.
- Не трогать: `technozrelost-frontend/` целиком; логи, сиды, тесты-фикстуры с русским (рабочее тело); алгоритмические константы.
- Если не хватает зависимости — не ставить, вернуть `BLOCKED: <имя>` с причиной.
- Один таск — один коммит. Коммитит только оркестратор — исполнителям коммитить ЗАПРЕЩЕНО.

## Из таска 01 — каталог

- `ERROR_HEADER="X-Error-Code"`; `raise_error(код[, параметры])` (вызов: `raise raise_error(...)`); `get_message`, `resolve_locale`, `locale_from_request`, `readiness_text`
- Ключи `AUTH_*` и др. + `READINESS_TEXTS` (14 меток + 44 текста + 64 требования); EN — TRL/CNTR/R&D (спорные на приёмке)
- Тесты: `uv run pytest -q`, один файл — `uv run pytest <путь> -q`

## Из таска 02 — миграция закрыта (коммит 969f68a)

- Паттерн везде: `raise raise_error(CODE[, params], request=request)`; FILE_TOO_LARGE=422, FILE_UPLOAD_TOO_LARGE=413
- Валидаторы кидают коды; main-хендлер переводит по Accept-Language (ru default, fallback без падения)
- Общий `file_storage.to_http_exception`; мёртвые константы удалены

## Из таска 03 — конфиги и сверка (коммит 9ffc9c2, сюита 403 зелёная)

- `settings.registry_anon_limit: int = 120` (env `REGISTRY_ANON_LIMIT`, имя в `.env.example` без значения); тест на шве settings
- Сканер: backend user-text 122→43 (остаток — OpenAPI-описания, сиды, маппируемые raises), config-url 8 (7 дефолтов в config + 1 FP) — честный предел
- Живьём на свежем :8000: AUTH_INVALID/AUTH_REQUIRED ru/en, ready ok; sibling-константы REGISTRY_AUTH_LIMIT/WINDOW/MAX_ENTRIES — следующий проход по конфигам
