# 07 — TLS sslip.io и строгий гейт деплоя

**Требования:** G02, G40, G41
**Blocked by:** 01
**Зона:** `technozrelost-backend/infra/`
**Волна:** 3
**Status:** ready

## Что должно заработать

Временный публичный адрес на базе IPv4 через sslip.io отдаётся по доверенному TLS с автообновлением; HTTP редиректит на HTTPS. Деплой падает на localhost, HTTP-URL, Salon-несоответствии сертификата и скорой экспирации вместо молчаливого самоподписанного fallback.

## Из брифа, дословно

> «Публичный MVP»
> «Пока сделаем без домена на публичном ipv4»
> «sslip.io + HTTPS»

## Разделы спецификации

Истории 8, 37–38; Решения §5; Швы `infra-single`, `acceptance`.

## Критерии приёмки

- [ ] Техническое имя резолвится в IPv4 сервера; цепочка сертификата валидируется публично без флагов доверия
- [ ] HTTP редиректит на HTTPS; финальный health-гейт идёт без отключения проверки сертификата
- [ ] Dry-run обновления сертификата успешен; обновление перезагружает nginx без провала readiness
- [ ] `NEXTAUTH_URL` и CORS соответствуют публичному хосту; localhost отклоняется
