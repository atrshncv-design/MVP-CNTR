# Спецификация P3 — RU↔EN + таблица + WCAG + offline

## Задача
P1/P2 закрыли ЛК/реестры/matching, но платформа только на русском, реестры только карточки, доступность базовая, offline нет.

## Решение
Весь интерфейс RU↔EN тумблер (next-intl, без тёмной темы), переключатель карточки/таблица в реестрах, WCAG AA, offline-очередь.

## Истории
| # | Метка | История | Приёмка |
|---|-------|---------|---------|
|1|R01|Как пользователь, я переключаю RU↔EN в шапке и вижу весь интерфейс на выбранном | тумблер в топбаре, locale в cookie, 300+ ключей |
|2|R02|Как пользователь, я переключаю реестр карточки↔таблица | тумблер, таблица с колонками ID/Название/УГТ/Статус/Бюджет |
|3|R03|Как пользователь с клавиатурой, я прохожу WCAG AA | axe 0 нарушений |
|4|R04|Как пользователь offline, я ставлю действие в очередь | баннер offline, очередь sync после online |

## Решения
Стек next-intl, messages/ru.json+en.json, middleware locale, таблица @tanstack/react-table или рукописная, offline via localStorage queue + Background Sync, WCAG via axe.

## Границы
| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `i18n` | перевод | `useTranslations()` | messages |
| `registry/table` | таблица | `RegistryTable` | колонки |
| `a11y` | WCAG | axe | |
| `offline` | очередь | `useOfflineQueue` | sync |

## Вне рамок
Тёмная тема — не делаем (заменена переводом)
