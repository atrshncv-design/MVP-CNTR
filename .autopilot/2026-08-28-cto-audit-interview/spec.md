# Спецификация: CTO-глубинное интервью — платформа Технозрелость (единое окно НТР)

## Задача

Я solo-CTO ЦНТР без опыта B2G-масштаба. Код платформы есть (Next.js 16 + FastAPI + PG 16/pgvector + MinIO/ClamAV), P0 частично закрыты (`N-01`, `FE-01/02`, `P-01` done, `INF-01..07` code/local pending). К декабрю нужно показать главе республики **единое цифровое окно НТР**: оценка готовности по ГОСТ Р 58048-2017, ведение проектов по УГТ 1-9, реестры компетенций региона (МТК/ВУЗы/проекты/УГТ/технологии), **автоподбор исполнителей (мэтчинг)**, управленческая отчётность, геймификация, 99.9% аптайм. Пик — 5-10К одновременных (65% чтение реестров/15% запись доков/15% Туно/ <1% админы, `GMT+4` 8-18, проект 5-20 чел), LLM 500-1000 conc, регистрация email+Яндекс/VK, данные — хаотичный ingest (API/ручной/пользователи) с открытыми/закрытыми частями. ТЗ нет, бюджет платит ЦНТР (смета нужна), команда = я + AI-агенты (bus-factor=1), вехи 01.10/01.11/01.12. Интервью должно дать карту системы на 1 странице, вес пользователя, сервер под 5К и 10К, PII-контур (локальная чистит → облако обезличенно, в MVP только скрипты), два RAG-контура Туно/Каба-Инмар без смешения, и план 90 дней с отчётами пн/ср/пт.

## Решение

К концу прогона CTO получает:
1. **Проверенный аудит** — `docs/BACKLOG.md` 65 пунктов верифицирован, `P0` 5 done + 9 external pending зафиксированы с файлами:строками.
2. **Карта на 1 странице** `Большое интервью 280826/02-карта-системы-1-страница.md` — поток `nginx→frontend→backend→Primary/Replica→MinIO/ClamAV→RAG→LLM`, пулы `config.py:38`, `RPO 5м` `postgresql-pitr.conf:13`, `RTO 1ч` `rehearse_pitr.sh`.
3. **Вес пользователя и сервер** — таблица `06-сервер-10К.md`: читатель 5МБ/0.02 CPU, писатель 50МБ/0.08, Туно 30МБ×3с; пилот 8/32 (500 VU) vs 5К 84 ГБ 2 хоста vs 10К 166 ГБ 3 хоста + pgbouncer + WAL-offsite `wal-archive-prod-data:39`.
4. **Смета** — тикет `01-smeta-budget.md` с чек-листом (CPU/RAM/disk на контейнер, RPO/RTO, offsite crypt `backup.sh:322`, LLM 500/1000, 152-ФЗ) для передачи сметчику.
5. **УГТ и документы** — скриптовый контур `stages.py:202` `all(uploaded)` + `notify_managers` `manager.py:44` fail-closed, шаблоны `v1→v2` `models.py:467`, паспорт/смета/NDA, дефекты race/UNIQUE зафиксированы.
6. **RAG изоляция** — миграция `0028 contour CHECK(tuno,kaba)` два ivfflat `WHERE`, `POST /chat/tuno/kaba` `rag.py:26`, `LLM_GATEWAY_ENABLED` + allowlist PII (в MVP `false`), `html_sanitizer.py` nh3.
7. **Геймификация** — 66 медалей `seed_achievements.py:28` анализ: 2 триггера live, 32 мертвы, `ON CONFLICT` `achievements.py:141` + `sha256` вместо `title`.
8. **Процесс solo:** `01.10/01.11/01.12`, отчёты пн/ср/пт `Plan.md:215`, `ADR` `docs/adr/`, `runbook` + Deputy, `CODEOWNERS`, `Kali` пентест + внешний аудит после тикетов.

## Решения по реализации

- **Карта:** `interfaces.md` §Границы, `02-карта` — один источник правды.
- **Сервер:** старт 8/32 (`Plan.md` пилот), масштаб через `deploy.replicas` + `pgbouncer` + `Redis` `P-04`, не переписывая `database.py:1`.
- **Смета:** отдельный тикет `01-smeta-budget.md` — сметчик считает ₽/мес, CTO проверяет чек-лист.
- **УГТ:** убрать `UNIQUE(from_level,to_level)` → `(from_level,title)`, `trigger` при `success is None` → `pending_manager`, `notify` на каждый `clean` `stages.py:423`.
- **RAG:** миграция 0028 `contour`, два индекса, `POST /chat/tuno|kaba`, `POST /rag/templates` с `contour`, запрет ingest без тега.
- **PII:** `Settings.llm_gateway_enabled` `config.py:57`, allowlist полей, `nh3` `html_sanitizer.py`, в MVP `false`.
- **Геймификация:** `UNIQUE(user_id,achievement_id,COALESCE(event_ref,''))`, `INSERT ON CONFLICT`, `sha256` `achievements.py:234`.
- **Процесс:** `ADR` 5 строк, `runbook` видео 5м, `vault` секретов, техотчёт пн/ср/пт, Kali + внешний аудит после `build`.
