## Что должно заработать

Контентные данные с русским текстом внутри кода (методология УГТ, витрина, метки отраслей) берутся из словарей обеих локалей; неймспейсы и конвенция ключей заданы для всех следующих тасков.

## Из брифа, дословно

> «вносить правки и исправить хардкод»
> «исправить хардкод на другой какой-то вариант»
> «Особенно критично, когда хардкод касается отображения слов»

## Разделы спецификации

Истории 1–7, Решения §1–§3, Швы.

## Критерии приёмки

- [ ] В `src/lib/` не осталось кириллических литералов, уходящих на экран (методология, витрина, справочники — через `t()`)
- [ ] Ключи лежат в неймспейсах `ugt`, `showcase`, `taxonomy`, внесены в обе пары словарей ru+en
- [ ] Сканер по зоне показывает ноль строк экрана вне словарей, паритет ключей — ноль расхождений
- [ ] `npm run lint`, `npm test` — зелёные
- [ ] Тест на шве: ключ из каждого нового неймспейса резолвится в обеих локалях
