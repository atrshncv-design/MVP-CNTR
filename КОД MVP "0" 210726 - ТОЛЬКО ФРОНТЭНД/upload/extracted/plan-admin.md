# План: Админ-панель УГТ Платформы

## Цель
Создать админ-панель для управления исполнителями и заказчиками платформы оценки УГТ.

## Структура

### 1. Страница входа (/login)
- 3 типа входа: "Исполнитель", "Заказчик", "Администратор"
- Поля: email, пароль (stub)
- Перенаправление в соответствующий кабинет

### 2. Админ-дашборд (/admin)
- KPI карточки: всего исполнителей, заказчиков, проектов на оценке
- Графики активности
- Таблица последних действий
- Быстрые ссылки на разделы

### 3. Раздел "Исполнители" (/admin/performers)
- Список всех исполнителей (таблица)
- Фильтры: тип, направление, УГТ, приоритет, статус
- CRUD: добавить, редактировать, удалить
- Поля карточки:
  - Название организации/группы
  - Тип (ВУЗ / НИИ / Научная группа / Институт / Лаборатория / Стартап)
  - Направление исследований
  - Текущий УГТ
  - Контактное лицо (ФИО, должность, телефон, email)
  - ЛПР (ФИО, должность, телефон, email)
  - Приоритет (Высокий / Средний / Низкий)
  - Статус (Активный / На рассмотрении / Архив / Чёрный список)
  - Примечания / пометки
  - Дата добавления

### 4. Раздел "Заказчики" (/admin/customers)
- Список заказчиков (таблица)
- Фильтры: отрасль, тип, приоритет, статус
- CRUD: добавить, редактировать, удалить
- Поля карточки:
  - Название компании
  - Тип (Промышленник / Отраслевик / Госкорпорация / Средний бизнес)
  - Отрасль (авиация, энергетика, нефтегаз, машиностроение, IT, оборона, etc.)
  - Контактное лицо
  - ЛПР
  - Требования к проектам (список)
  - Приоритет
  - Статус
  - Примечания
  - Дата добавления

### 5. Детальная карточка (/admin/performers/:id, /admin/customers/:id)
- Полная информация
- История изменений
- Пометки
- Быстрые действия

### 6. Навигация админ-панели
- Sidebar с разделами
- Header с поиском и профилем
- Breadcrumbs

## Техническая реализация
- localStorage для хранения данных (demo-режим)
- React Context для auth state
- Route guards для /admin
- Таблицы с сортировкой, фильтрацией, пагинацией
- Modal формы для добавления/редактирования
- Toast уведомления
