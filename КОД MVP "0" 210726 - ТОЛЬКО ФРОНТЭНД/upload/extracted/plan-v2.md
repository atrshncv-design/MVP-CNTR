# План улучшений УГТ Дашборд v2

## Цель
Улучшить дашборд с 5 ключевыми изменениями на основе лучших практик UI-UX Pro Max

## Задачи

### 1. Улучшение UI дизайна (ui-ux-pro-max-skill + magic-mcp)
- Применить лучшие практики: Soft UI, улучшенный Glassmorphism, Neumorphism карточки
- Добавить hover-эффекты с плавными transitions (150-300ms)
- Улучшить типографику и отступы
- Добавить кастомные анимации Framer Motion
- Улучшить accessibility (WCAG AA)

### 2. Раскрывающиеся поля под критериями оценки
- Для каждого критерия в Assessment добавить `description` — подробное пояснение
- Добавить Accordion/Expandable блок под каждым чекбоксом
- По клику раскрывается описание что означает критерий

### 3. Кнопки-заглушки "Скачать образец" в плане перехода
- В Roadmap рядом с каждым документом добавить кнопку
- Стилизовать под образец документа с иконкой скачивания

### 4. Кнопки-заглушки в "Ключевые документы"
- В LevelDetail рядом с каждым deliverable добавить кнопку "Скачать образец"

### 5. Решения для рисков
- В Roadmap добавить блок "Риски" с возможными рисками для каждого перехода
- Под каждым риском указать "Решение" — конкретные действия

## Этапы реализации

### Stage 1: Обновление данных (ugtData.ts)
- Добавить descriptions для assessment criteria
- Добавить documents[] с templateFile для roadmap transitions
- Добавить risks[] с solutions для roadmap transitions
- Добавить documents[] для UGT levels deliverables

### Stage 2: Обновление страниц (параллельно)
- Assessment: раскрывающиеся описания + улучшенный UI
- Roadmap: кнопки документов + риски с решениями + улучшенный UI
- LevelDetail: кнопки документов + улучшенный UI
- Home + Methodology: улучшенный UI
