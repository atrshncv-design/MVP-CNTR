## 1. Резюме для руководителя (1 страница)

**Что это:** B2B/B2G платформа ЦНТР по ГОСТ Р 58048-2017 — оценка технозрелости (УГТ 1–9), ведение НИОКР-проектов, реестры организаций/НИОКТР, документы, достижения, AI-помощники.

**Где мы сейчас:**
- Код есть и он большой: backend 13,5 тыс строк (`app/**/*.py`), frontend 29 маршрутов, 32 миграции БД, 110 API-эндпоинтов, 36 таблиц. Это не прототип на бумаге.
- Локально всё собирается и тесты зелёные: backend `334 passed` (`technozrelost-backend/tests`), frontend `39 passed` (`technozrelost-frontend/tests/*.test.mjs`), `ruff`/`mypy --strict`/`eslint`/`next build` — зелёные на dev-машине (см. `docs/Status.md:8-12`).
- **Но** это локальная проверка. На прод-сервере заказчика система **ещё не развёрнута и не измерена**: бэкапы/offsite/PITR/Telegram/rollback-нагрузка — `code/local done; external pending` (`docs/BACKLOG.md:34-44`, `reports/loadtest_report.json: stub`).

**Что можно показать сегодня (демо без сервера заказчика):**
1. Лендинг + 9 личных кабинетов (все роли работают).
2. Регистрация → проект → загрузка документов → УГТ N→N+1 → реестр.
3. Новости, достижения (66 медалей), файлы с антивирусом, SSE-уведомления.

**Что нельзя обещать:** 10 000 одновременных, 300–500 RPS, RPO 5 мин/RTO 1 ч, 99,9% — это **цели**, не измерения (`docs/СЕРВЕР-ТРЕБОВАНИЯ-2026.md:92-96`). До прод-benchmark любая цифра — допущение.

**До декабря 2026 реалистично:** закрыть блокеры безопасности (P0) до 30.09, стабилизировать до 15.11 (заморозка), провести приёмку на стенде заказчика. Для этого нужен доступ к серверу + 2 КП на железо (`966 000 ₽ оценка`, `docs/СЕРВЕР-ТРЕБОВАНИЯ-2026.md:450-461`).

**До декабря 2027:** три этапа — завершение MVP → пилот на 20–50 орг. → промэксплуатация + AI-усиление. Команда сейчас bus-factor=1 (только CTO + AI-агенты, `docs/Plan.md:17`); для промэтапа нужны люди.

## 2. Фактический статус проекта

### 2.1 Архитектура (факт из кода)

```
Browser → nginx:443 → frontend:3000 (SSR, rewrites /api/v1 → backend)
                    → backend:8000 ×2 → PostgreSQL Primary:5432 (запись)
                                      → PostgreSQL Replica:5433 (чтение, hot standby)
                                      → Redis (SSE/pubsub, rate-limit)
                                      → MinIO:9000 (файлы) → ClamAV:3310 (скан)
                                      → pgvector (1536-мерный вектор) → внешний LLM
Monitoring: Prometheus:9090 → Grafana:3000; Operations: backup-timer, wal-offsite, alerter
```

### Этап 2 — Пилот (16.11.2026 → 31.03.2027) — РАБОЧАЯ ГИПОТЕЗА
