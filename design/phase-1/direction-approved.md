## Implementation meaning

Direction B becomes the production baseline for the shared platform shell:
horizontal global navigation, a clear project context header, local workspace
tabs, a dominant process/state panel, and one visually primary next action.

light operational surfaces, restrained status colors, and high data clarity.

The approval does not authorize prototype data in production. Every project
state, deadline, actor, readiness value, document count, and transition
condition must come from an API response or an explicit loading/empty/error
state.
