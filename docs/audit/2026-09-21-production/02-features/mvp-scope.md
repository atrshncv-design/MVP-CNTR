# 02 — MVP scope: planned vs regression; dead-code notes

## Граница MVP (spec, дословно по смыслу)

- Доступно сейчас: реестр, поддержка, консалтинг, сотрудничество, поиск и аналитика.
- Готовятся к запуску: оценка УГТ и переходы (матрица F-018: реализовано статически, запуск не заявлен).
- В разработке: патентование, акселерация, внутренние AI-контуры (матрица F-029/F-030: отсутствие — не regression).
- Целевая топология 2×R640 — вне прогона; текущий single-node — факт для SPOF-оценки.

## Что отделено от regression

| Группа | Статус в матрице | Почему не regression |
|---|---|---|
| УГТ-оценка и переходы | F-018 `EXPECTED` | Граница MVP: готовятся к запуску |
| Патентование, акселерация | F-029 `STUB` | Граница MVP: в разработке |
| Внутренние AI-контуры, LLM-шлюз | F-030 `DISABLED` | Граница MVP + default-off |
| P2-заглушки клиента | F-028 `STUB` | Задекларированы в коде (`p2GatedMessage`) |
| Saved-filters backend | F-033 `STUB` | Отложенная интеграция с документированным fallback (`BLOCKED.md`) |
| Ролевой runtime | `UNKNOWN` везде | R36: нет test accounts — не считается ни пройденным, ни сломанным |

## Dead code: подтвержденного нет

Правило тикета: dead code не заявляется по одному grep. Проверки ниже — минимум
два сигнала (ссылки + назначение/история), вывод — только `alive` / `indeterminate`.

- `tuno`/`kaba` (chat-подконтуры): совпадения в `chat.py`, `ai_assistant.py`,
  `rag.py`, `matching.py`, `api-client.ts`, `models.py`, `schemas.py`, `config.py` —
  множественные ссылки через слои. Вывод: alive, не dead.
- `DELETE .../files/old-versions`: роутер в `requests.py` + комментарий про retention.
  Клиентские вызовы не проверялись в этом тикете. Вывод: indeterminate, кандидат
  для security/UX-проверки, не заявлен как dead.
- `questionnaire_results` рядом с новыми `assessment_*` таблицами: обе линейки
  присутствуют в моделях и миграциях; какая реально пишется — нужен рантайм/схема БД.
  Вывод: indeterminate, передано в отчёт по БД (зона ticket 03/06), не заявлен как dead.
- `SavedFilters`/`useSavedFilters`: используется в `FilterBar.tsx`, `index.ts`,
  `api-client.ts`, сообщениях `ru/en/zh`. Вывод: alive (с fallback, см. F-033).

Итог: ни одна единица кода в этом тикете не помечена как dead; кандидаты выше —
рабочий список для следующих отчётов, а не выводы.
