# 28 — Фронтенд: ЛК менеджера — две очереди верификации

**What to build:** В ЛК Менеджера ЦНТР — две вкладки: «Новые проекты» (черновики на апрув: карточка, радар, предварительная оценка → «Подтвердить и присвоить УГТ N» / «Отклонить с причиной») и «Заявки на повышение УГТ» (документы + заключение системы + подтверждающие материалы от регулирующей организации → «Подтвердить уровень» / «Отклонить с причиной»).
