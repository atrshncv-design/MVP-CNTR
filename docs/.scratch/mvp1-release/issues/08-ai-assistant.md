# 08 — AI-ассистент: OpenAI-совместимый клиент

**What to build:** Заменить GigaChat-обёртку на универсальный OpenAI-совместимый клиент (переменные окружения `LLM_API_BASE`, `LLM_API_KEY`, `LLM_MODEL`; ключ пользователь кладёт в `.env` сам).
