# 03 — Схема данных механики вступления

**What to build:** Миграция БД: у проектов появляется уникальный join-токен (случайная строка вида `TZ-XXXXXX`, не предсказуемая перебором, не числовой id); таблица участников проекта расширяется полями `status` (`active|pending|removed`), `invited_by`, `is_priority`; генерация токена при создании проекта; аудит-записи при изменении членства.
