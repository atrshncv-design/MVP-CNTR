# 12 — Фронтенд: сквозной сценарий ГосКомпании

**What to build:** Визард опросника на финальном шаге создаёт проект и сохраняет ответы (POST + ответы по уровням) и ведёт на дашборд проекта. Карточка проекта: кнопки «Сгенерировать документ» (ТЗ/Паспорт/ТЭО с показом текста), «Поделиться» (копирование токена/ссылки), «Заявки на вступление» (одобрить/отклонить), «Регенерация токена» (для приоритетных). Статистика ЛК ГК — из API (вместо хардкода). Битые ссылки («Загрузка ТЗ», карточки уровней) убраны или исправлены.

**Blocked by:** 05 — Создание проекта и сохранение опросника; 06 — Механика вступления; 07 — Генерация документов
