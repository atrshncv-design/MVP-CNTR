# 04 — RBAC на бэкенде: владение проектами

**What to build:** Закрыть дыры доступа: чтение/изменение проекта — только владельцу, активным участникам и ролям ЦНТР (админ/менеджер); `require_role` применяется к админским эндпоинтам (пользователи, шаблоны RAG); проверки доступа во всех project-эндпоинтах (детали, опросник, генерация).

**Blocked by:** 03 — Схема данных механики вступления

**Status:** ready-for-agent

- [ ] Админ/менеджер ЦНТР видят все проекты
- [ ] Админские эндпоинты защищены `require_role`
