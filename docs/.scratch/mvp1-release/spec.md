## 1. Контекст и цель

Платформа «Технозрелость» (B2B/B2G, ЦНТР Удмуртской Республики, ГОСТ Р 58048-2017) — MVP v2
уже написан (Next.js 16 + FastAPI + PostgreSQL/pgvector), большинство механик реализовано и
подтверждено QA (19/19 тикетов). Цель релиза: к 31.08.2026 полностью рабочий MVP, который
можно показать заказчику по демо-маршруту и развернуть на сервере (сервер предоставят коллеги).

**Одна история продукта (итог интервью 03.08):** любой участник центра (учёный, ГК, МТК и др.)
регистрируется → запускает **экспресс-оценку УГТ** из своего ЛК → получает предварительный
уровень → это создаёт **проект-черновик** → менеджер ЦНТР **апрувнует карточку и присваивает
официальный УГТ** → проект виден всем в **общем реестре** (+ автоматически в **реестре
технологий** при УГТ 7+) → проект **дорабатывается уровнями N→N+1**: при полном комплекте
документов этапа **автоматически формируется заявка**, система даёт **предварительную оценку
по ГОСТам** (RAG), менеджер **верифицирует** → УГТ повышен.

Критерий качества: **никаких багов** — интеграционные тесты + ручной прогон демо-маршрута
(чек-лист приёмки, §8.2).

## 3. Функциональный состав

### 3.1. Демо-маршрут (новый, ~10 минут; решение №18)

1. **Регистрация/вход** любой из 9 ролей (живая регистрация) → ЛК
2. **Экспресс-оценка УГТ** из ЛК: визард опросника по 9 уровням (4 категории: научная/техническая/организационная/производственная) → радар + предварительный УГТ → создаётся **проект-черновик**
3. **ЛК Менеджера ЦНТР → вкладка «Новые проекты»**: карточка + радар + предварительная оценка → «Подтвердить и присвоить УГТ N» → **официальный УГТ**
4. **Общий реестр проектов** (все роли видят карточку с УГТ-уровнем и радаром); при УГТ 7+ проект **автоматически** виден в реестре технологий (фильтр «УГТ 7+»)
5. **Доработка документами**: карточка показывает список документов следующего этапа (N→N+1) → загрузка → комплект собран → **автозаявка** → **предварительная оценка по ГОСТам** («принято / чего не хватает»)
6. **ЛК Менеджера → вкладка «Заявки на повышение УГТ»**: документы + заключение системы → «Подтвердить уровень» → **УГТ повышен**
7. *(Бонус)* **Регулирующая организация** присоединяется к карточке по токену TZ-XXXXXX → добавляет документ подтверждения УГТ → материал в очереди менеджера
8. *(Бонус, если останется время)* Генерация документов (ТЗ/Паспорт/ТЭО) + AI-ассистент по ГОСТам

### 3.2. Ядро: флоу верификации УГТ (новое, решения №3–17)

- **Экспресс-оценка** — любой пользователь из своего ЛК: опросник → предварительный УГТ → проект-черновик (владелец — оценивавший). Переоценка существующего проекта НЕВОЗМОЖНА.
- **Черновик → официальный проект**: менеджер апрувнует карточку (соответствие действительности) и присваивает официальный УГТ. Черновики/отклонённые видят только владелец и менеджер.
- **Два реестра**: общий реестр проектов (все роли) + реестр технологий = фильтр «УГТ 7+» над тем же реестром (автоматическое попадание). Фильтры: УГТ, область технологии, бюджет и др.
- **Этапы повышения (N→N+1, 8 этапов)**: словарь документов этапа (LLM по ГОСТам один раз → верификация методологом центра) → полнота комплекта = триггер **автозаявки** → предварительная оценка документов LLM по ГОСТам (RAG) → успех → очередь менеджера → верификация → УГТ повышен; неуспех → список недостающего → дозагрузка → повтор.
- **Единый авторитет по УГТ — менеджер ЦНТР** (две очереди, §3.3). Регулирующая организация — внешний источник подтверждающих документов (не монопольный).

## 4. Механика вступления в проект (join-токен, подтверждено + дополнение №11)

- У каждого проекта — **join-токен** `TZ-XXXXXX` (случайная строка, нечитаемая перебором; внутренний числовой id остаётся в БД). Ссылка вида `/join/TZ-XXXXXX`.
- **Два уровня доверия**:
  - Приоритетный шаринг (создатель проекта / админ / менеджер ЦНТР / участник с `is_priority=true`) → вступление **автоматическое** (сразу `active`).
  - Ручной ввод токена или шаринг неприоритетным участником → **заявка** (`pending`), одобряет приоритетный участник.
- В карточке проекта: кнопка «Поделиться» (копирует токен/ссылку), список «Заявки на вступление» (одобрить/отклонить/сменить роль), регенерация токена.
- **Менеджер ЦНТР**: выдаёт/снимает `is_priority` любому участнику проекта.
- **Регулирующая организация (№11)**: присоединяется к карточке по токену как участник; после вступления получает доступ к добавлению верифицирующих документов (подтверждение УГТ). Механика переиспользует существующую join-логику без новой сущности.
- Трекинг в БД: `project_members.status` (`active|pending|removed`), `invited_by`, `joined_at`, `is_priority`; записи в `audit_trail` (кто/когда/по какому токену).
- Вступивший выбирает роль в проекте сам; приоритетный участник может изменить при одобрении.
- Один активный токен на проект; регенерация инвалидирует старый.

## 8. Тестирование

### 8.1. Автоматизированное

- **Backend (pytest, тестовая БД — схема `test`):** существующие 66 тестов (демо-маршрут, join-токен, RBAC, генерация, контрольные точки, чат) + новые: экспресс-оценка → черновик → апрув менеджера → присвоение УГТ → попадание в реестры (в т.ч. автопопадание в реестр технологий при УГТ 7+); автозаявка по полноте комплекта этапа (кто бы ни залил последний документ); предварительная оценка документов (мок LLM); очереди менеджера (decide approve/reject с причиной); RBAC регулирующей организации (документы только после join по токену); переоценка созданного проекта запрещена (403).
- **Frontend:** `next build` + `tsc --noEmit` + eslint; смоук ключевых страниц.

### 8.2. Критерии приёмки 31.08 (чек-лист, решение №19 — на живых данных)

1. **Регистрация** любой из 9 ролей → вход → ЛК с реальными данными
2. **Экспресс-оценка УГТ** из ЛК → черновик с предварительным УГТ (ответы в БД)
3. **ЛК менеджера**: апрув карточки → официальный УГТ присвоен
4. Проект виден в **общем реестре** (все роли); при УГТ 7+ — в **реестре технологий**
5. Загрузка документов → **автозаявка** → предварительная оценка → верификация менеджером → **УГТ повышен** (лента статусов, история)
6. **Регулирующая организация** присоединяется по токену и добавляет документ подтверждения → материал в очереди менеджера

Плюс: все 9 ЛК рабочие без моков; 66+ тестов зелёные; регресс прежнего QA (опросник, join-токен, реестры, генерация, ассистент).
