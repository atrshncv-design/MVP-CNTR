# 08 — Менеджерская верификация УГТ

**What to build:** Дать менеджеру очередь и полный процесс подтверждения или возврата УГТ с причинами, рекомендациями и повторными попытками.

**Blocked by:** 07 — автозаявка

**Status:** done

- [x] После первичного подтверждения разрешён только N→N+1
- [x] Решение manager-only и транзакционно меняет уровень/статус
- [x] Отказ содержит критерии, документы, причину и рекомендации
- [x] Повторная попытка создаётся только после изменения полного комплекта
- [x] История попыток неизменяема
