# 13 — Архивирование, аудит и экспорт проекта

**What to build:** Дать владельцу безопасное архивирование, участникам проектную ленту, администратору полный аудит и пользователю переносимый экспорт проекта.

**Blocked by:** 04, 09, 10 — права, история и публичность

**Status:** done

- [x] Пустой черновик удаляем, верифицированный проект только архивируем
- [x] Проектная лента доступна участникам по правам
- [x] Глобальный аудит append-only для администратора
- [x] Экспорт содержит карточку, подтверждённые документы, заключения и решения
- [x] Закрытые данные не попадают в публичный API


## Реализация (05.08.2026)

- Backend `01a12a0`: DELETE /projects/{id} (только пустой черновик), POST /projects/{id}/archive (верифицированный — только архив, скрывает из реестра), GET /admin/audit (append-only, админ), GET /projects/{id}/export (JSON: карточка, решения, документы; без join_token/payload). **165/165 pytest, ruff чист** (4 новых теста).
- Frontend `ec5f130`: кнопки «В архив» и «Экспорт» в карточке.
