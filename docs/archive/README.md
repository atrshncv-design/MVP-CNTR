# Архив документации

Исторические материалы сохранены, но исключены из обычного поиска агентов через
корневой `.ignore`. Это предотвращает смешивание старых планов с актуальными
`docs/Plan.md`, `docs/BACKLOG.md` и `docs/Status.md`.

## Разделы

- `project-history/` — завершённые трекеры отдельных ранних работ.
- `project-planning/` — прошлые версии дорожных карт и промежуточные расчёты.
- `project-research/` — интервью, исходные смыслы и исследовательские материалы.
- `remediation/` — выполненные планы, спецификации и таски прошлых аудитов.

Архив не является источником текущего состояния. Используйте его только для
исторической проверки или по прямой ссылке из ADR и отчётов.
