# 25 — Мэтчинг поля (Q34)

Источник Q34

LLM берет полный контекст карточки -> сопоставляет с БД -> топ-5 с описанием обоснования.

Рекомендуемый v1 набор (без PII, токены ~800):
- `title` + `annotation` (full text, до 2000 знаков, режется `file_url[:600]` `stages.py:127`)
- `sector` `seed_achievements.py:137` 7 отраслей + `nioktr_types` JSONB GIN
- `ugt_level` 1-9 + `doc_type`
- `region` (Удмуртия/другая)
- `competencies` / `keywords` (из `nioktr_cards`)
- Не брать v1: `budget`, `contacts`, `closed` (PII, 152-ФЗ, токены)

LLM prompt: "Проанализируй технологию {title+annotation} sector {sector} ugt {level} region {region} через призму технологии, найди 5 неочевидных применений в БД с аргументацией почему полезно".

Обоснование: sector+ugt дают кросс-отрасль (wood->furniture), annotation — неочевидность, region — локальность ЦНТР.
