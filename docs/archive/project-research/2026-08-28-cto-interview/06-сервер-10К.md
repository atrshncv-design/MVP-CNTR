# 06 — Сервер 10К (вес пользователя)

## Вес
Читатель 65% 930 RPS 0.02 CPU 5МБ, Писатель 15% 215 RPS 0.08 CPU 50МБ + ClamAV 1с, Туно 15% 215 RPS 1000 conc 30МБ×3с, Админ <1%

## Пилот (презентация, 500 VU): 8 vCPU/32 ГБ NVMe 200+50 WAL
Хватит с p95 500мс, RPO 5м, RTO 1ч.

## Цель 10К: ~59 vCPU/166 ГБ кластер 3 хоста
nginx 2/2, frontend×4 8/16, backend×8 16/24 + pgbouncer 1/2, PG Primary 16/64+200 WAL, Replica 8/32, Redis 2/8, MinIO 4/16/2Тб + ClamAV 2/4.
32 vs 64 vs 128: 32 — пилот, 64 — минимум 10К на одном хосте без HA, 128 — только с локальной LLM 13B +64ГБ.
