# Задача агенту-разработчику: публичный посадочный многостраничник платформы «Технозрелость»

**Ветка:** `codex/recovery-frontend` → коммит + push в `origin` (push-контракт).
**Запрещено менять:** контракты API, `src/app/dashboard/**`, `src/app/login`, `src/app/register`, `src/app/api/auth/**`, файлы бэкенда.

---

## 1. Контекст

Платформа «Технозрелость» — цифровая B2B/B2G-инфраструктура Центра НТР Удмуртии (ЦНТР УР): оценка уровня готовности технологий (УГТ) по ГОСТ Р 58048-2017, реестры проектов и технологий, 9 ролей участников. Сдача MVP1 — 31.08.2026.

Сейчас человек без регистрации видит только голую страницу (`src/app/page.tsx` — заголовок + две кнопки) и ничего не узнаёт о центре, методике, уровнях УГТ, заказчиках, исполнителях, дорожной карте. **Нужен публичный посадочный многостраничник** — «витрина» платформы для незалогиненных посетителей.

**Референс:** в `КОД MVP "0" 210726 - ТОЛЬКО ФРОНТЭНД/public/app/` лежит собранный React-SPA-прототип MVP0, у которого был именно такой посадочник. Его роуты: `/` (Главная), `/methodology` (Методика), `/levels` + `/level/:id` (Уровни УГТ с детальными страницами), `/customers` + `/customers/:id` (Заказчики), `/performers` + `/performers/:id` (Исполнители), `/roadmap` (Дорожная карта), `/mindmap` (Карта связей), `/assessment` (Оценка проекта), `/login`. **Взять структуру и контент MVP0 как основу, но переделать визуально под текущую дизайн-систему (п. 3)** — не копировать вёрстку MVP0.

**Стек:** Next.js 16 (App Router), React 19, Tailwind v4, framer-motion, lucide-react. Шрифты уже подключены в `src/app/layout.tsx` через `next/font/google`: Inter (`--font-inter`, sans+display) и JetBrains Mono (`--font-jetbrains_mono`, mono).

## 2. Что сделать

Заменить содержимое `src/app/page.tsx` на полноценную главную и добавить публичные маршруты:

| Маршрут | Содержание |
|---|---|
| `/` | Hero с УТП (цифровая платформа трансфера технологий ЦНТР УР, оценка УГТ по ГОСТ Р 58048-2017), CTA «Оценить УГТ своего проекта» → `/register` и «Войти» → `/login`; блок «Как это работает» (3 шага: экспресс-оценка → верификация менеджером ЦНТР → доработка уровнями N→N+1); блок «9 ролей участников» (ГК, R&D-исполнитель, научная организация, серийный производитель, инвестор, аудитор, менеджер/админ ЦНТР, регулирующая организация); блок «Уровни УГТ 1–9» (тёплая шкала) со ссылкой на `/levels`; блок «Дорожная карта»; финальный CTA |
| `/about` | О центре: миссия ЦНТР УР, что даёт платформа, нормативная база (ГОСТ Р 58048-2017 и пакет методических ГОСТов), контакты |
| `/methodology` | Методика оценки УГТ: описание системы 9 уровней, 4 категории (научная / техническая / организационная / производственная готовность), как проходит оценка на платформе (визард → радар → предварительный УГТ → верификация) |

## 3. Дизайн — строго текущая дизайн-система (тёмная тема 2.0)

**Внимание:** `DESIGN.md` в корне устарел (описывает светлую тему v1). **Источник истины — фактические токены в `src/app/globals.css`** (`:root`, секция «Фирменная палитра»). Не переопределять их, не вводить новые hex-цвета вне токенов.

Ключевые токены:
- Фон/поверхности: `--color-tz-bg: #070b16`, `--color-tz-surface: #0f1729`, `--color-tz-surface-2: #131d36`
- Текст: `--color-tz-fg: #e8edf7`, `--color-tz-secondary: #a9b7d0`, `--color-tz-muted: #7f90b3`
- Границы: `--color-tz-border: #223050`, `--color-tz-card-border: #243050`
- Акцент и бренд-градиент (синий → фиолетовый → бирюза): `--color-tz-accent: #2e5bff`, `--color-tz-violet: #7c5cff`, `--color-tz-teal: #00d4c8`
- УГТ-шкала (тёплая): `--color-tz-ugt-low: #ff7a2e`, `--color-tz-ugt-mid: #e5c840`, `--color-tz-ugt-high: #a8d65a`
- Статусы: `--color-tz-success`, `--color-tz-warning`, `--color-tz-danger`

Правила:
- Фоновые свечения (radial-градиенты violet/blue/teal) и инженерная сетка уже реализованы на `body::before/::after` в `globals.css` — **не дублировать**, лендинг ложится поверх автоматически.
- Анимации: framer-motion (появление секций fade-up со stagger), готовые keyframes `tz-rise` в globals.css — использовать; никаких «прыгающих» элементов и бесконечных вращений.
- Иконки — только `lucide-react`, эмодзи запрещены.
- Один акцент на экран (не более 2 применений `--color-tz-accent`); градиент blue→violet→teal — только для hero/ключевых CTA, не для каждой карточки.
- Типографика: Inter (заголовки/текст), JetBrains Mono — для УГТ-уровней (`УГТ 4`), номеров, метаданных. Бейджи уровней — моноширинные.
- Glass-эффект: карточки на `--color-tz-surface` с `--radius-tz-card` и `--shadow-tz-card` (или полупрозрачные `rgba`-поверхности с blur — допустимо для hero).
- Responsive: без горизонтального скролла на 360–430px; мобильное меню (бургер); крупные заголовки через `clamp()`.
- Первичные кнопки — с реальной глубиной (`--shadow-tz-glow` допустим для главной CTA), hover-состояния цветные.

## 4. Данные — честность, без моков

- Публичная зона работает **без авторизации**. Живой реестр проектов (`GET /api/v1/projects/registry`) сейчас отдаёт 401 без токена — **не подключать и не мокать** проекты на лендинге. Если нужны живые цифры (кол-во проектов, организаций) — это отдельная задача на бэкенд (публичный read-only эндпоинт), сформулировать как открытый вопрос, НЕ решать молча.
- Весь маркетинговый контент (о центре, методика, уровни, роли) — статический, из MVP0 и спеки. Это нормально.
- Навигация auth-aware: при наличии сессии (`auth()` из `@/auth.config` — паттерн уже есть в текущем `page.tsx`) показывать «Войти в личный кабинет» (`ROLE_DASHBOARD[роль]` из `@/lib/roles`) вместо «Вход/Регистрация».

## 5. Технические требования

- Публичные страницы — React Server Components (кроме клиентских обёрток для framer-motion/menu).
- Не трогать `dashboard/**`, `login`, `register`, auth-роуты. Лендинг — только `src/app/page.tsx` + новые файлы в `src/app/` (например `about/page.tsx`, `methodology/page.tsx`, `levels/page.tsx`, `levels/[id]/page.tsx`, `customers/`, `performers/`, `roadmap/`).
- В worktree лежат **незакоммиченные изменения дизайн-системы (тёмная тема 2.0)** — это основа, не откатывать; закоммитить их отдельным коммитом (`design: тёмная тема 2.0 — дизайн-система платформы`) перед коммитом лендинга.
- Гейты перед сдачей: `npm run lint` + `npx tsc --noEmit` + `npm run build` — зелёные.
- **Пифолл:** не запускать `npm run build` при живом dev-сервере (ломает NextAuth-роуты — зависает логин). Если dev-сервер запущен — сначала остановить, после build запустить `rm -rf .next` и dev заново.
- Коммиты в `codex/recovery-frontend`, push в `origin` (push-контракт).

## 6. Критерии приёмки

1. `/` без авторизации показывает полноценную витрину: hero с УТП, «Как это работает», 9 ролей, уровни УГТ, дорожная карта, CTA «Оценить УГТ».
2. Все маршруты из таблицы п. 2 открываются без авторизации, без горизонтального скролла на мобильном (360px), меню работает.
3. Никаких моков проектов/статистики; контент — из MVP0 и спеки; тексты осмысленные.
4. Логин/регистрация/все дашборды не сломаны (регресс: вход через `/login`, ЛК любой роли).
5. При залогиненном пользователе навигация показывает «Войти в личный кабинет».
6. lint + tsc + build зелёные; коммиты запушены в `origin` (`codex/recovery-frontend`).
7. Вёрстка на токенах тёмной темы (п. 3) — ни одного хардкод-hex вне `globals.css`.

- Актуальные тексты о ЦНТР УР (миссия, достижения, контакты) — взять из MVP0; если у заказчика есть обновлённые — заменить позже.
