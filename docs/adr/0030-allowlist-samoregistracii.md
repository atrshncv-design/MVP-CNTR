# ADR 0030: Allowlist саморегистрации и отзыв миграцией

## Контекст
Запрет по принципу «все кроме привилегированных» пропускает новую роль наружу по умолчанию.

## Решение
Саморегистрация разрешает только явный allowlist непривилегированных ролей, привилегии выдаёт только администратор, ранее выданное наружу отзывается миграцией данных.

## Почему
Отвергается denylist «кроме staff»: ломается fail-open при добавлении каждой новой роли. Отвергается ручная чистка через админку: невоспроизводима и неаудируема.

## Последствия
Новые роли закрыты по умолчанию, выдача аудируема. Неприятное: каждую новую роль нужно осознанно классифицировать, иначе регистрация падает; отзывная миграция необратима и требует бэкапа.
