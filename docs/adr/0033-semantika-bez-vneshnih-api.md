# ADR 0033: Семантика без внешних API с reindex-скриптом

## Контекст
Хеш-корзины токенов не знают синонимов, а сопоставление заявляется по смыслам.

## Решение
Семантика строится на обучаемой embedding-модели внутри контура без внешних API, смена модели сопровождается скриптом полной переиндексации.

## Почему
Отвергаются хеш-корзины: не дают синонимы и проваливают оценку на синонимах. Отвергается внешний embedding-API: вводит зависимость от сети и провайдера, выводит данные за контур, даёт неконтролируемый дрейф.

## Последствия
Поиск понимает синонимы офлайн, данные не покидают контур. Неприятное: модель версионируется и хранится, смена требует времени и диска на полную переиндексацию.
