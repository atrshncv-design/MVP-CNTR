# ADR 0032: Backup-lock fail-closed с кодами 0/1/2/3

## Контекст
Миграция без готового бэкапа оставляет поломку без точки восстановления.

## Решение
Миграции требуют свободного lock: 0 означает бэкап готов и путь открыт, 1 означает lock занят и путь заблокирован, 2 означает состояние неизвестно и путь заблокирован, 3 означает ошибка вызова и путь заблокирован.

## Почему
Отвергается fail-open при занятом lock: бэкап пропускается именно когда идёт параллельная работа. Отвергается «предупреждение в лог без блокировки»: не останавливает опасную миграцию.

## Последствия
Ни одна миграция не идёт без бэкапа, исходы различимы кодом. Неприятное: зависший lock или сбой хранилища lock останавливает деплой до ручного разбора.
