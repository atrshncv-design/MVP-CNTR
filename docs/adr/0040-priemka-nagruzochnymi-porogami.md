# ADR 0040: Приёмка нагрузочными порогами

## Контекст
Предыдущая оценка мощностей отозвана как недоказуемая, доверие держится только на замере.

## Решение
Каждый пакет принимается по порогам: 50 одновременных пользователей, не менее 99% успеха, API p95 не более 1 с, страницы не более 2 с, RAM ниже 80%.

## Почему
Отвергается приёмка на глаз и по логам: не ловит деградацию под пиком. Отвергается разовый замер без порогов: цифры несравнимы и не дают вердикта pass/fail.

## Последствия
Вердикт воспроизводим, предел контура известен заранее. Неприятное: прогон требует стенда и времени перед каждым пакетом, пороги режут запуск при честном провале.
