# ADR 0019 — Архив ZIP по папкам по темам как физическая форма

**Дата:** 2026-09-03
**Статус:** принят
**Tier:** T2 — reestr-kompetencii-udgu

## Контекст
R25 — прямой запрос «хочу архив, где по папкам разбиты файлы по темам». R06/R06.2 — Кашин боится ошибиться в имени папки/листа. R23 — развилка «таблички vs документы». Нужно одновременно удобство человека (разложить по темам) и детерминизм пайплайна (найти что парсить), плюс место для «грязных» файлов без чистки (R14).

## Решение
Единственная физформа — ZIP `УдГУ_потенциалУР_YYYY-MM-DD.zip` (рекомендация имени, не строго). Корень: `README_УдГУ_выгрузка.md`, `00_опись.xlsx`, `00_опись.pdf`, `raw/` (опционально), `01_кафедры_и_лаборатории/` … `07_люди_эксперты/` + расширяемые `08_...`. Правило: таблички — ядро в `00_опись.xlsx`, документы/фото/паспорта — приложения в папках, связь — ссылкой из ячейки. Пайплайн: unzip + CRC → поиск `00_опись.xlsx` по шаблону имени с fallback «любой .xlsx в корне» → индексация папок по нормализованному имени.

## Почему (с отвергнутыми)
- **Один Excel без папок — отвергнут:** некуда приложить фото оборудования, PDF-статьи, сканы патентов (R11.1/R12).
- **Набор разрозненных файлов без ZIP — отвергнут:** теряется атомарность выгрузки, нет CRC-проверки на битую передачу (R25.1).
- **Облачная папка / SFTP — отвергнут:** требует инфры и доступа для разовой MVP-выгрузки, противоречит офлайн-CLI (Wave1 за дни).
- **Один PDF/Word — отвергнут:** не машиночитаем, как в ADR-0018.
- **Строгая схема имён без нормализации — отвергнут:** R06.2 требует толерантности — lowercase/без пробелов + отчёт «нераспознанная папка X — проигнорирована, ожидаются …».

## Последствия
- Плюс: человек раскладывает интуитивно, пайплайн — детерминированно; пустая папка + «нет данных» в листе — валидно (R06.1); `raw/` принимает любое без требования форматирования (R14.1).
- Минус: ZIP ограничен размером, CRC-фейл — не падение, а отчёт «файл X не читается» + список успешно прочитанных; дублирование папка ↔ лист требует дисциплины, mitigated инструкцией `00_инструкция`.
- Цена: договорённость об именовании — социальный контракт, а не технический enforcement; при `08_...` нужен лист-шаблон, иначе пайплайн лишь проиндексирует файлы как `raw_refs`.
