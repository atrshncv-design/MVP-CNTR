# ADR 0037: Временный TLS через sslip.io

## Контекст
Домена нет и ждать его нельзя, а авторизация и обычные ПДн по открытому HTTP недопустимы.

## Решение
Публичное имя строится на публичном IPv4 через sslip.io, сертификат выпускается через ACME с автообновлением, HTTP редиректит на HTTPS.

## Почему
Отвергается покупка домена сейчас: бюрократия блокирует запуск. Отвергается HTTP или самоподписанный сертификат: первый светит пароли, второй даёт предупреждения и подрывает доверие.

## Последствия
Доверенный HTTPS доступен сразу без домена. Неприятное: имя техническое и привязано к адресу, смена IP или переезд на постоянный домен требуют перевыпуска и перенастройки.
