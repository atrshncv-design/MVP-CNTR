# ADR 0039: Трёхпакетный релиз с gating

## Контекст
Объём первого релиза спорный, реестры рискованно открывать с непроверенными данными.

## Решение
Поставка идёт тремя пакетами — инфраструктура, затем инфоконтур с ЛК и AI/RAG, затем публичные реестры, каждый следующий начинается только после приёмки предыдущего, реестры и matching до P3 скрыты на уровне навигации, роутов и клиента.

## Почему
Отвергается всё одним релизом: сырые реестры уходят в публичность без точки остановки. Отвергаются реестры в P2 с пометкой: скрытие только на словах не держит границу.

## Последствия
После каждого пакета можно легально остановиться, состав релиза проверяем. Неприятное: полная ценность приходит только к P3, gating требует дисциплины приёмок и честных пустых состояний в P2.
