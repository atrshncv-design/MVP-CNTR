# ADR 0038: RAG deny-by-default только по ГОСТам через внешний endpoint

## Контекст
Корпус ГОСТов уже имеется, ключ есть у владельца, провайдер внешний и глобальный, ПДн и данные проектов выносить нельзя.

## Решение
Ассистент и RAG-поиск отвечают только по корпусу ГОСТов с цитатами, всё остальное запрещено по умолчанию, вопросы обезличиваются, провайдер подключается как OpenAI-совместимый endpoint, секреты фигурируют только именами.

## Почему
Отвергается пропуск ПДн и проектов во внешний AI: утечка невосстановима. Отвергается локальный LLM сейчас: требует памяти и времени вне конверта. Отвергается собственный адаптер: дублирует работу при готовом совместимом интерфейсе.

## Последствия
Ценность AI видна в первом релизе без расширения доверенного контура. Неприятное: зависимость от внешнего провайдера и сети, ответы ограничены ГОСТами, matching и отчёты откладываются.
