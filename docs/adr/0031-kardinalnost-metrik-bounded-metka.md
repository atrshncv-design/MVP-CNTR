# ADR 0031: Кардинальность метрик через карту после роутеров и bounded-метку

## Контекст
Метки из входных данных растят число серий и ломают мониторинг и exposition.

## Решение
Карта роутов строится после подключения всех роутеров, значения меток экранируются, несопоставленные пути складываются в одну ограниченную метку.

## Почему
Отвергается сырой путь как метка: уникальные ID дают взрыв серий. Отвергается построение карты до регистрации роутов и неэкранированные значения: дают несопоставления и ломают exposition.

## Последствия
Число серий ограничивается числом роутов, exposition не ломается. Неприятное: детализация по нешаблонным путям теряется, роут добавленный после построения карты молча уходит в bounded.
