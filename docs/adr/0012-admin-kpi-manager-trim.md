# ADR 0012: Админка max vs Менеджер урезан — единый центр KPI 12 (R24, 19-)

**Tier:** T2 — UX/roles isolation, reversal = утечка бюджета и перегруз менеджера
**Date:** 2026-08-28
**Status:** accepted

## Title
Админ — единый центр управления (KPI 12), менеджер — только очереди верификации

## Context
Админ `cntr_admin/page.tsx` 792стр показывал 3 KPI, менеджер `cntr_manager/page.tsx` 85стр видел `Бюджет портфеля:72` и `Все проекты:79` + очереди — роли смешивались, бюджет утекал к операционке. Требуется fail-closed разделение (FE-01) и KPI для ЦНТР-надзора.

## Decision
- `cntr_admin`: расширен до 12 KPI (Пользователи/Активных/Назначений ролей/Всего проектов/Черновиков/Опубликовано/Бюджет портфеля/Новых в очереди/Заявок на повышение/Очередь pending/Застрявших 90д+/Всего наград) — данные из `/admin/achievements/stats`, `/manager/queue`, `/projects`, `/metrics` queue_pending; сетка 4×3, `data-testid=admin-kpi-grid`, доступ только `cntr_admin` (require_role).
- `cntr_manager`: урезан — убран `Бюджет портфеля` (Wallet) и `Все проекты` (tab + карточка + fetch `/projects`), оставлены только `Новые проекты` + `Заявки на повышение УГТ` + `В очереди всего` (3 карты, 2 таба); профили/организации остаются via `ProfileVerificationQueue`.
- Матрица `ROUTE_ALLOWED_ROLES` уже fail-closed (`/dashboard/cntr_admin` только cntr_admin).

## Consequences
**Положительные:** админ видит всю картину для надзора ЦНТР (26- KPI расширение); менеджер не видит финансовые агрегаты (152-ФЗ, принцип наименьших привилегий); меньше запросов менеджера (нет `/projects`).

**Отрицательные:** админ тянет 4 запроса на загрузку KPI — нагрузка на лимиты registry (смягчено кэшем); менеджер теряет обзор портфеля (компенсируется админкой read-only).

**Что отвергли:** оставить бюджет менеджеру — отвергнуто (19- явный запрет); дублировать все KPI менеджеру — отвергнуто (нарушение разделения).
