# ADR 0042: Доказательный аудит с явным `UNKNOWN`

## Контекст

Аудит сопоставляет локальную версию, Git, сервер и production, но часть runtime-проверок может быть недоступна без test accounts, credentials или отдельного разрешения. Нельзя превращать отсутствие наблюдения в утверждение о работоспособности.

## Решение

Каждое существенное утверждение привязывается к санитизированному evidence ID с source, командой, target, временем и результатом. Статус без достаточного доказательства получает `UNKNOWN`; статический или локальный результат явно не маркируется как deployed. Секреты и персональные данные в доказательства не сохраняются.

## Почему

Отвергнуты выводы по намерению кода, HTTP 200 или текстовому поиску: они не доказывают фактическое поведение и дают ложную уверенность. Отвергнуто молчаливое исключение недоступных сценариев: оно скрывает пробелы приёмки. Отвергнут сбор сырых логов и credential-материалов: доказательность не оправдывает риск утечки.

## Последствия

Отчёт воспроизводим, а границы знания видны владельцу; gate-решение не маскирует недостающие проверки. Цена — больше реестров и случаев `UNKNOWN`, которые требуют отдельного безопасного доступа или test accounts перед закрытием.
