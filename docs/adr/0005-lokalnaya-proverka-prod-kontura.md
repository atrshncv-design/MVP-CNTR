## Контекст

Цель — готовность к деплою на сервер госзаказчика; единственная копия проекта на этой машине, настоящий деплой — необратимое внешнее действие вне контроля агента.

## Решение

Продукционный контур проверяется локально: `infra/docker-compose.prod.yml` поднимается на этой машине, health/readiness зелёные, нагрузочный сценарий прогнан против дефолтных целей; настоящий деплой выполняет пользователь по инструкции из отчёта.

## Почему

Отвергли деплой агентом: необратимо, отката со второй копией нет, ответственность за внешний сервер несёт пользователь. Отвергли проверку только dev-контура: dev-сборка ничего не доказывает про прод-композицию — секреты, healthcheck'и, restart-политики существуют только в prod-файле.

## Последствия

«Готовность к деплою» означает локально зелёный контур, а не работающий сервер: различия машины и сервера (сеть, домены, ОС) проявятся только у пользователя при настоящем выводе. Нагрузочные цифры сняты с одного ноутбука и не экстраполируются на прод-железо.
